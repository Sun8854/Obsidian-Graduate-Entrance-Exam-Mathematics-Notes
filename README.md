## 📖 项目简介

本仓库是在 [BlandAlpha/obsidian_math](https://github.com/BlandAlpha/obsidian_math) 公开内容基础上的 **二次整理与扩展**,以 Obsidian Vault 形式组织, 主攻考研数学二。

在保留原项目框架的基础上, 本仓库重点补充了以下内容:

| 模块             | 说明                                     | 位置                                                        |
| :------------- | :------------------------------------- | :-------------------------------------------------------- |
| 📝 **题目解答**    | 例题 / 习题 / 1000 题手写解答过程                 | `Excalidraw/例题/` · `Excalidraw/习题/` · `Excalidraw/1000题/` |
| 📚 **知识归纳**    | 从第四讲起的知识点详细总结(前几讲持续补全中)                | `0. 杂项/题目/` 对应章节文件                                        |
| 🤖 **AI 课程总结** | 基于课程逐字稿+课本整理的笔记,例题讲解更细,内容更全,但**重点不突出** | `AI课程总结/基础篇/第12讲~15讲/`                                    |
| 🧮 **核心计算通关**  | 核心计算套路与易错点讲义(目前仅整理第一组,欢迎继续补充)          | `0. 杂项/题目/核心计算通关讲义/`                                      |

## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/Sun8854/Obsidian-Graduate-Entrance-Exam-Mathematics-Notes.git
cd Obsidian-Graduate-Entrance-Exam-Mathematics-Notes
```

> 💡 仓库体积较大(包含大量 SVG 手写解答),如不需要历史可使用浅克隆:
> ```bash
> git clone --depth=1 https://github.com/Sun8854/Obsidian-Graduate-Entrance-Exam-Mathematics-Notes.git
> ```

### 2. 在 Obsidian 中打开

1. 启动 **Obsidian**(最新稳定版)
2. `Open vault` → 选择刚刚克隆的仓库根目录
3. 打开 `欢迎！.md`, 或者直接进入对应的**主目录**:
   - [高等数学主目录.md](./高等数学主目录.md)
   - [线性代数主目录.md](./线性代数主目录.md)

## ⚙️ 环境配置

### 必需插件(没有几乎无法正常浏览)

| 插件 | 作用 |
|:---|:---|
| **Excalidraw** | 渲染手写解答的 `.excalidraw` 与导出的 SVG |
| **Mehrmaid** | 渲染 Mermaid 流程图/时序图 |
| **Image Converter** | 处理高分辨率手写图片的缩放与排版 |

### 推荐启用

| 插件 | 作用 |
|:---|:---|
| **LaTeX Suite** | 行内/块级 LaTeX 编辑增强(片段、补全) |
| **Outliner** | 大纲视图折叠导航 |
| **Dataview** | 进阶:聚合题目/标签生成自定义视图 |

> ⚠️ **未安装必需插件** 时, 部分笔记会出现**显示为代码块**而非渲染图形的现象。
