# 考研数学二高频考点与听课顺序

## 一、先看结论

推荐按下面的顺序听《张宇高等数学18讲》：

**导学 → 第1讲 → 第2讲 → 第3讲 → 第4讲 → 第5讲 → 第8讲 → 第9讲 → 第10讲 → 第15讲 → 第13讲 → 第14讲 → 第6讲 → 第11讲 → 第7讲 → 第12讲**

数学二可以暂不听：**第16讲、第17讲、第18讲**。

截至抓取时，课程页显示第1讲已经学完，第2讲正在学习。因此当前最合适的衔接方式是：

**先完成第2讲剩余内容，再按第3 → 4 → 5 → 8 → 9 → 10 → 15 → 13 → 14讲推进。**

这个顺序同时考虑了两件事：

1. 知识依赖：先极限和一元微分，再积分、多元微分、二重积分和微分方程。
2. 真题收益：优先覆盖近五年反复出现、分值较高的章节。

## 六、推荐听课顺序

### 阶段0：先掌握课程语言

#### 导学课

- 目的：理解课程反复使用的“目标—程序—细节”三向解题法。
- 听法：如果已经听过，不必完整重听，只需复习自己的导学笔记。

### 阶段1：补齐所有后续章节的前置工具

#### 第1讲 → 第2讲 → 第3讲 → 第4讲

- 第1讲负责函数极限、无穷小和连续。
- 第2讲负责递推数列和数列极限；近五年“求数列极限”出现3年。
- 第3讲负责导数、微分、可导性等概念。
- 第4讲负责导数、高阶导数、隐函数和参数方程计算。

当前执行：**第1讲不必重听，先续完第2讲，再听第3、4讲。**

### 阶段2：拿下一元微积分高分区

#### 第5讲 → 第8讲 → 第9讲 → 第10讲

- 第5讲对应单调性、极值、最值、凹凸、拐点、渐近线。
- 第8讲重点对应反常积分判敛，近五年5年都考。
- 第9讲解决不定积分、定积分、变限积分、反常积分计算。
- 第10讲对应定积分几何应用，近五年累计51分。

这四讲应精听，课后分别做对应真题，不要只看视频。

### 阶段3：攻克近五年最稳定的综合章节

#### 第15讲 → 第13讲 → 第14讲

1. 第15讲微分方程
   - 高阶常系数微分方程近五年5年都考。
   - 一阶微分方程近五年出现4年，历史覆盖26年。
2. 第13讲多元函数微分学
   - 偏导数、全微分近五年5年都考。
   - 多元函数极值近五年出现4年。
3. 第14讲二重积分
   - 交换积分次序与坐标系近五年出现4年、累计49分。
   - 区域对称性与奇偶性是近期升温点。

这三讲是强化阶段后半程的最高优先级。

### 阶段4：补证明题和综合方法

#### 第6讲 → 第11讲

- 第6讲处理中值定理、零点、微分等式和微分不等式。
- 第11讲处理积分等式和积分不等式。
- 这些考点历史稳定，但近五年不如计算类考点密集，可以放在主干计算章节之后集中突破。

### 阶段5：补数学二专属应用

#### 第7讲 → 第12讲

- 只听物理应用部分。
- 经济应用属于数学三内容，可以跳过。
- 定积分物理应用近五年出现3年，但内容相对集中，适合最后专题补齐。

### 阶段6：明确跳过范围

#### 第16—18讲

- 第16讲无穷级数：标准目录标为数学一、数学三内容。
- 第17讲多元函数积分学预备知识：数学一内容。
- 第18讲多元函数积分学：数学一内容。

数学二备考阶段不建议在这里投入时间；如当年课程或考试大纲调整，以最新版数学二大纲为准。

## 七、听课时的执行规则

### 1. 每讲只提取三类内容

- **题目信号**：看到什么条件，应该联想到本讲的哪种题型。
- **处理程序**：第一步、第二步、第三步分别做什么。
- **细节检查**：定义域、端点、单侧、参数范围、可逆条件、重根或共振等。

### 2. 重点章节的最低练习要求

- 第3—5讲：导数计算、单调极值、凹凸渐近线各做一组真题。
- 第8—10讲：反常积分、积分计算、几何应用分别训练。
- 第13讲：偏导与全微分、多元极值分别训练。
- 第14讲：画区域、换序、极坐标必须独立训练。
- 第15讲：一阶方程和高阶常系数方程分开训练。

### 3. 线性代数必须另排课程

这条链接只有高等数学18讲，不覆盖数学二约20%的线性代数分值。线代建议另按以下顺序听：

**矩阵基础 → 向量组 → 线性方程组 → 特征值与相似对角化 → 二次型 → 行列式专项补漏**

其中应最优先保证：

1. 二次型概念、标准形和合同变换。
2. 相似与相似对角化。
3. 非齐次方程组、向量线性表出与线性相关性。
4. 伴随矩阵、可逆矩阵和矩阵初等变换。

## 八、统计限制

- 研可岸是真题整理站，不是官方命题机构，高频统计不能等同于押题。
- 870道题中有202道只标到章节节点，没有继续细分到叶子考点。因此单考点排名主要基于668道细分题，章节和模块统计则使用全部870道题。
- 老年份与现行考试大纲存在差异，所以听课优先级以近五年为主，40年历史频次只用于判断长期稳定性。
- 启航目录和学习进度可能继续更新，本笔记记录的是2026-09-06抓取到的状态。
