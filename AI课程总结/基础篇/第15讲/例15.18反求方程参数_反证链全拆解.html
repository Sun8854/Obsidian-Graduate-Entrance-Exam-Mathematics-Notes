第 15 讲 · 第六节 · 例 15.18 · 反求方程参数

"x·ex 是齐次解"为什么推出 "r=1 至少二重根"

一个题目如果直接正面判不出来,我们用反证法:假设 → 推矛盾 → 推翻假设。 这道题一共三步反证,绕了三个弯才把 y* 拆清楚,最后才"翻译"成根的结构。本文把整条反证链逐句拆开,让你看到每一步为什么这么想、推出什么、为什么够了。

1. 题目复述

EX 15.18 · 教材 full.md:89
设二阶常系数线性微分方程 $$y'' + \alpha\, y' + \beta\, y = \gamma \mathrm{e}^{x}$$ 的一个特解为 $$y^{*} = \mathrm{e}^{2x} + (1+x)\mathrm{e}^{x}$$ 确定常数 α, β, γ,并求该方程的通解。

题目的"已知信息"看起来就两个:方程右边长什么样 + 一个特解。三个未知数全藏在特解的拆分里。

老王原话:"这个对大家的解的结构要求是很高的,请大家认真把这个题目理解透彻。"

2. 拆题之前,你需要的三件工具

反证链里所有推理都靠这三条结论撑起来。先把工具摆出来,后面推理时直接用。

TOOL 1

"特解之差 = 齐次解"

若 y₁*, y₂* 都是同一个非齐方程的特解, 则 $$\;y_1^{*} - y_2^{*}\;\text{满足对应的齐次方程}\;y'' + \alpha y' + \beta y = 0$$

为什么? 两个都满足 y''+αy'+βy=γex, 相减时左边是线性的(差)而右边 γex - γex = 0。
TOOL 2

齐次方程的解有可加性

齐次方程是线性方程: y₁, y₂ 都是解 → y₁ + y₂ 也是解。所以 复合的齐次解可以拆开,每一份也都是齐次解。

反过来说: 如果你知道 y₁ + y₂ 是齐次解, 拆出的 y₁, y₂ 也不一定是 齐次解, 因为它们可能还要满足别的方程。但在本节里, 我们只用 "特解之差" 的方向, 不需要走这一条。
TOOL 3

特征根 ↔ 通解结构对应表(上一节讲的)

二阶齐次方程 y'' + αy' + βy = 0 的特征根决定通解长什么样,只有以下 3 种可能:

特征根 通解形式 解空间里有谁
两个不等实根 r₁ ≠ r₂ C₁er₁x + C₂er₂x 只有 er₁x 和 er₂x
二重实根 r₁ = r₂ = r (C₁ + C₂x) erx erx 和 x·erx 都出现
共轭复根 α ± βi eαx(C₁cos βx + C₂sin βx) 两个三角函数
秒杀观察
上表里只有第 2 种会让齐次解里同时出现 erx 和 x·erx。 所以反过来:齐次解里一旦有 x·erx 露面 → r 至少是二重根。这是后面整节的核心。

3. 反证链总览(全图先看一眼)

整条推理分三段反证,每段都是"假设 → 推矛盾",完了再回到正确方向。最后一步才"翻译"成根的结构。

STEP 0 先拆 y*
STEP 1 假设 e2x 是非齐特解 → 推出根冲突 → 矛盾
STEP 2 假设 ex 是非齐特解 → x·ex 是齐次解 → 推出 3 个线性无关解 → 矛盾
STEP 3 唯一可能: ex 也是齐次解 → 写出特征方程 → 定参数
RETURN 翻译成根结构

下面挨个拆开。

4. STEP 0 · 把 y* 拆成三段

第一件事不是判别,是先把 y* 写顺:

拆分 $$y^{*} = \mathrm{e}^{2x} + \mathrm{e}^{x} + x\mathrm{e}^{x}$$

三段分别是:

  • e2x · 单指数,系数 1
  • ex · 单指数,系数 1
  • x·ex · 指数乘 x 的一次项

问题:这三个东西,哪些是齐次解,哪个是非齐特解?

5. STEP 1 · 反证 e2x 是非齐特解

假设

假设 e2x 是非齐特解

那意味着 e2x 代进方程 y''+αy'+βy=γex,右边必须等于 γex。

但 e2x 代入后左边是某个 ·e2x,指数是 2,不可能 配出右边 ex(指数是 1)。所以假设不成立。

直观解释: 自由项是 γex, 形式上只有 ex 和 x·ex, x²ex, ... 这些项有资格进非齐特解(由待定系数法的设定)。指数 2 不在这个名单里, 所以 e2x 只能是齐次解。
结论
e2x 是齐次方程的解 → r = 2 是特征根。

6. STEP 2 · 反证 ex 是非齐特解(整道题最难的一段)

这一段是反证链的核心。先把整个推理画出来,然后逐句讲。

图 1 · 反证链流程图 · 从假设到矛盾
A

假设: ex 是非齐方程 y''+αy'+βy=γex 的特解

这就是我们要反的东西。开始反。

B

推导 1: y* − ex 也是非齐方程的特解

两个东西都是非齐方程的特解(题设 y* 是,假设里 ex 也是),所以相减还是非齐特解。

用 TOOL 1: 两个非齐特解作差 → 右边 γex − γex = 0 → 满足的是齐次方程。 所以 y* − ex 是齐次解(不是非齐特解,刚才那句话写得不准确,这里纠正一下)。
重要更正
正确叙述: 题设 y* 是非齐特解(整条),我们假设 ex 也是非齐特解。两者作差 y* − ex = e2x + x·ex, 满足齐次方程(右边 γex - γex = 0)。所以 e2x + x·ex 是齐次解。
C

推导 2: x·ex 也是齐次解

已知 e2x + x·ex 是齐次解,e2x 也是齐次解(STEP 1 推出来的)。

把两个齐次解 作差:(e2x + x·ex) − e2x = x·ex。 齐次方程对"差"也封闭,所以 x·ex 满足齐次方程。

关键观察: 这次是用"齐次解对减法封闭"(它本身就是线性的)。这比 TOOL 2 的"可加性"更直接。
D

推导 3: 用 TOOL 3 反查根 → r = 1 至少二重根

现在齐次方程的解空间里同时出现了 ex 和 x·ex。

查 TOOL 3 的对应表:只有"二重实根"这种情况才会让 erx 和 x·erx 同时出现。所以 r = 1 至少是二重根。

"至少"的含义: 不一定是恰好二重根,也可能是三重、四重,但至少是二重。这里因为是二阶方程,所以"至少二重"= "恰好二重"。
E

推导 4: 跟 STEP 1 的 r = 2 矛盾

二阶齐次方程的特征方程是 一元二次,最多 2 个根(按重数计)。

现在它已经"占据"了:

  • r = 2 占 1 个名额(来自 e2x 是齐次解)
  • r = 1 占 2 个名额(因为至少二重根)

总数 1 + 2 = 3 > 2, 装不下!

矛盾确认
假设 "ex 是非齐特解" 推出 r=1 至少二重,跟 r=2 同时出现在二阶方程里名额冲突 → 假设不成立。

7. STEP 3 · 反过来: ex 必是齐次解

STEP 2 推翻了假设,所以 ex 不是非齐特解。

那它是什么?回到 y* 的拆分:

y* = 三段 $$\underbrace{\mathrm{e}^{2x}}_{\text{齐次解(STEP 1)}} + \underbrace{\mathrm{e}^{x}}_{?} + \underbrace{x\mathrm{e}^{x}}_{\text{非齐特解(STEP 2 推出的唯一选项)}}$$

整个 y* 是非齐特解,拆开的三段里:

  • e2x 已是齐次解
  • x·ex 只能是非齐特解(如果它也是齐次,那 y* 整个退化成齐次解,矛盾)
  • 剩下的 ex 不是非齐特解(刚证了) → 它也只能是齐次解
结论
齐次方程的两个线性无关解已经确定: $$\overline{y} = C_1 \mathrm{e}^{x} + C_2 \mathrm{e}^{2x}$$ 对应特征根 r₁ = 1, r₂ = 2, 特征方程 $$(r-1)(r-2) = r^2 - 3r + 2 = 0$$

8. 回代定 α, β, γ

特征方程出来了,跟标准型 y'' + αy' + βy = 0 对比:

系数对比 $$y'' \;\underbrace{- 3}_{α}\; y' \;\underbrace{+ 2}_{β}\; y = 0 \;\;\Longleftrightarrow\;\; y'' + α\, y' + β\, y = 0$$

所以 α = −3, β = 2。

非齐方程现在是 y'' − 3y' + 2y = γex。把非齐特解 x·ex 代进去:

代入特解 $$(x+2)\mathrm{e}^{x} - 3(x+1)\mathrm{e}^{x} + 2x\mathrm{e}^{x} = \gamma \mathrm{e}^{x}$$

左边化简:

化简 $$[(x + 2) - 3(x + 1) + 2x]\mathrm{e}^{x} = \gamma \mathrm{e}^{x}$$ $$[x + 2 - 3x - 3 + 2x]\mathrm{e}^{x} = \gamma \mathrm{e}^{x}$$ $$-\mathrm{e}^{x} = \gamma \mathrm{e}^{x}$$

所以 γ = −1。

9. 最终答案

原方程
$$y'' - 3y' + 2y = -\mathrm{e}^{x}$$
通解
$$\boxed{\;y = C_1 \mathrm{e}^{x} + C_2 \mathrm{e}^{2x} + x\mathrm{e}^{x}\;}$$

其中 C₁, C₂ 为任意常数。

10. 整条反证链回头看

图 2 · 全链鸟瞰 · 假设 → 反推 → 矛盾 → 推翻
看到齐次解里有 xk-1·erx → 直接说 "r 至少 k 重实根"。
反证法只在不能直接判时才用, 大多数情况一眼翻译就够。

11. 易错点(踩坑汇总)

PIT 1 · "作差"的两个方向
非齐特解作差(右边抵消) → 得到的是齐次解。 齐次解作差(还是齐次) → 还是齐次解。本题里 STEP 2 的关键一步是非齐作差,不是齐次作差。
PIT 2 · "至少"不等于"恰好"
x·ex 露面 → r=1 至少二重根。 可能是三重、四重等,只是下限。只有在确定总名额后才能升级到"恰好"。
PIT 3 · 二阶方程最多 2 个根
n 阶常系数齐次方程最多 n 个根(按重数计)。 二阶 → 至多 2 个 → 这是名额冲突的来源。 算之前先数清"已占多少名额"。
PIT 4 · 反证假设设错对象
本题反的是 "ex 是非齐特解",不是反结论。 反证法要反的是"中间命题",不是"最终结论"(反最终结论会推出题目矛盾)。
PIT 5 · 没翻译到根结构就停
反证链走完只能确定"哪些是齐次解"。要定 α, β, γ 还得翻译成特征方程再代入。反证只是开胃菜,完整答案是"反证 + 翻译 + 代入"三段。
PIT 6 · 把"非齐特解"和"非齐通解"搞混
y* 是非齐的特解(一个具体的函数, 不带任意常数)。 y = 齐通解 + 非齐特解 是非齐的通解(带任意常数)。混了会以为 "y* 代进去算不出 γ"。
