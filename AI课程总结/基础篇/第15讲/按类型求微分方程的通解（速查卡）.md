## §1 一阶微分方程求通解

### §1.1 直接可分离变量型 

**判别**:能写成 $y' = f(x)\,g(y)$(物以类聚,人以群分)

**步骤**(四步走):

| 步骤 | 动作 |
|---|---|
| ① | 写成 $y' = f(x)\,g(y)$ |
| ② | 把 $g(y)$ 除到左边:$\dfrac{\mathrm{d}y}{g(y)} = f(x)\,\mathrm{d}x$(默认 $g(y)\ne 0$) |
| ③ | 两边同时积分(各积各的) |
| ④ | 解出 $y$ |

**秒杀**:
- $g(y)\equiv 1$ → 直接 $\int \mathrm{d}y = \int f(x)\mathrm{d}x$
- 多对数相加 → 写 $\ln C$ 利于合并
- 常数 $C$ 写在最外层,**不**每步加 $C$

---

### §1.2 换元后可分离 · $f(ax+by+c)$ 型

**判别**:右边是 $ax+by+c$ 的整体函数

**步骤**(五步走):

| 步骤 | 动作 |
|---|---|
| ① | 令 $u = ax+by+c$ |
| ② | 对 $x$ 求导:$\dfrac{\mathrm{d}u}{\mathrm{d}x} = a + b\,\dfrac{\mathrm{d}y}{\mathrm{d}x}$(关键:两边都求导,常数 $a,b,c$ 算清) |
| ③ | 解出 $\dfrac{\mathrm{d}y}{\mathrm{d}x} = \dfrac{1}{b}\!\left(\dfrac{\mathrm{d}u}{\mathrm{d}x} - a\right)$ |
| ④ | 代入原方程 → 化为可分离 → 积分 |
| ⑤ | **换回** $u = ax+by+c$(致命坑:不换回直接交卷 0 分) |

**扩展**(若右端不能直接写成整体,处理顺序):齐次型 → 一阶线性 → 伯努利 → 全微分方程

---

### §1.3 齐次型 

**判别**:形如 $y' = \varphi(y/x)$(右端只含 $y/x$ 的整体函数)

> ⚠️ **"齐次型" ≠ "齐次方程"** —— 齐次方程是 $f(x)\equiv 0$;齐次型是右端只含 $y/x$

**步骤**(三步走):

| 步骤 | 动作 | 公式 |
|---|---|---|
| ① | 令 $u = y/x$ | $y = ux$ |
| ② | 对 $x$ 求导:$\dfrac{\mathrm{d}y}{\mathrm{d}x} = u + x\,\dfrac{\mathrm{d}u}{\mathrm{d}x}$ | 乘积求导 |
| ③ | 代入原方程 → 化 $\dfrac{\mathrm{d}u}{\varphi(u)-u} = \dfrac{\mathrm{d}x}{x}$ → 两边积分 → 换回 $u = y/x$ | |

---

### §1.4 一阶线性 

**标准型**:
$$\boxed{y' + p(x)\,y = q(x)}$$

> "线性"指 $y$ 和 $y'$ 都是 1 次。若给的是 $a(x)y' + b(x)y = c(x)$,两边除以 $a(x)$(若 $a(x)\not\equiv 0$)化标准型。

**通解公式**(必背,直接套):
$$\boxed{y = \mathrm{e}^{-\int p(x)\,\mathrm{d}x}\!\left[\int \mathrm{e}^{\int p(x)\,\mathrm{d}x}\cdot q(x)\,\mathrm{d}x + C\right]}$$

**铁律**:
- 两个 $\int$ **不加** $C$(是"某一原函数"记号)
- **整体外加一个** $C$
- $\int p\,\mathrm{d}x = \ln|\varphi(x)|$ 时,$\mathrm{e}^{\pm\int p\,\mathrm{d}x}$ 可去绝对值
- 其他 $\ln u$ 不知正负 → 一律加绝对值

**4 步走**(套公式):

| 步骤 | 动作 |
|---|---|
| ① | 把方程化成标准型 $y' + p(x)y = q(x)$ |
| ② | 算出 $\int p(x)\,\mathrm{d}x$ 的某一原函数(不加 $C$) |
| ③ | 算出 $\int \mathrm{e}^{\int p\,\mathrm{d}x}\cdot q(x)\,\mathrm{d}x$ |
| ④ | 套公式,得通解;代入初始条件定 $C$ |

**讨性质时**:必须改写为**定积分写法**(上下限 $x_0 \to x$,内层 $x \to t$):
$$y = \mathrm{e}^{-\int_{x_0}^x p(t)\,\mathrm{d}t}\!\left[\int_{x_0}^x q(t)\,\mathrm{e}^{\int_{x_0}^t p(s)\,\mathrm{d}s}\,\mathrm{d}t + C\right]$$
- 上限是 $t$ **不是** $x$!
- 求极限 / 周期 / 有界 → 必用变限积分 + 洛必达

**交换 $x, y$ 角色**(走不通时的兜底):若 $y' = (\text{含 }x,y)/(更复杂)$ 拆不开,反着来,让 $x$ 当因变量、$y$ 当自变量,看是否变成标准型。

---

### §1.5 伯努利方程(数一专属)

**判别**:
$$y' + p(x)y = q(x)y^n,\quad n\ne 0,1$$

**步骤**:

| 步骤 | 动作 |
|---|---|
| ① | 令 $z = y^{1-n}$ |
| ② | 求导:$\dfrac{\mathrm{d}z}{\mathrm{d}x} = (1-n)y^{-n}\,\dfrac{\mathrm{d}y}{\mathrm{d}x}$,解出 $\dfrac{\mathrm{d}y}{\mathrm{d}x}$ |
| ③ | 原方程两边除 $y^n$ → 乘 $(1-n)$ 后整理 |
| ④ | 得到 $\dfrac{\mathrm{d}z}{\mathrm{d}x} + (1-n)p(x)z = (1-n)q(x)$(一阶线性!) |
| ⑤ | 套 §1.4 公式(把 $y \to z$)→ 解出 $z(x)$ → 换回 $y = z^{\frac{1}{1-n}}$ |

## §2 二阶可降阶方程求通解(数一/数二专属)

> **核心思想**:用换元把二阶降为一阶,回到 §1 套路

### §2.1 类型(1)/(3):$y'' = f(x,y')$ 或 $y'' = f(y')$ — 缺 $y$ 

**口诀**:**赶尽杀绝 $y$**(只要方程里没有 $y$,立即把 $y,y',y''$ 通通干掉)

| 步骤 | 动作 | 公式 |
|---|---|---|
| ① | 令 $y' = p$,其中 $p = p(x)$(是 $x$ 的函数) | $p' = \dfrac{\mathrm{d}p}{\mathrm{d}x}$ |
| ② | 求 $y'' = p'$ | |
| ③ | 代入原方程 → $\dfrac{\mathrm{d}p}{\mathrm{d}x} = f(x,p)$(一阶方程) | 按 §1 求 $p = \varphi(x,C_1)$ |
| ④ | 再积分 $y = \int \varphi(x,C_1)\,\mathrm{d}x + C_2$ | |

> **类型(3)** $y''=f(y')$(既缺 $y$ 也缺 $x$)→ 按本类型处理

### §2.2 类型(2):$y'' = f(y,y')$ — 缺 $x$ 

**口诀**:**斩草除根 $x$**(只要方程里没有 $x$,绝不允许 $x$ 在新方程里出现)

**关键差异**:$p$ 必须当 $y$ 的函数!

| 步骤 | 动作 | 公式 |
|---|---|---|
| ① | 令 $y' = p$,其中 $p = p(y)$(**$y$ 的函数**) | |
| ② | 用链式求导 $y''$ | $y'' = \dfrac{\mathrm{d}p}{\mathrm{d}x} = \dfrac{\mathrm{d}p}{\mathrm{d}y}\cdot\dfrac{\mathrm{d}y}{\mathrm{d}x} = p\,\dfrac{\mathrm{d}p}{\mathrm{d}y}$ |
| ③ | 代入原方程 → $p\,\dfrac{\mathrm{d}p}{\mathrm{d}y} = f(y,p)$(以 $y$ 为自变量) | 按 §1 求 $p = \varphi(y,C_1)$ |
| ④ | **再分离变量** $\dfrac{\mathrm{d}y}{\varphi(y,C_1)} = \mathrm{d}x$ | 两边积分 |
| ⑤ | $\displaystyle\int \dfrac{\mathrm{d}y}{\varphi(y,C_1)} = x + C_2$ | |

> ⚠️ **致命坑**:**$y''$ 不能写成 $p'$**(否则混进 $x$,新增复杂性)—— 必须写成 $p\,\dfrac{\mathrm{d}p}{\mathrm{d}y}$

### §2.3 两种类型的对比

| 维度 | 类型(1)/(3) 缺 $y$ | 类型(2) 缺 $x$ |
|---|---|---|
| 口诀 | 赶尽杀绝 $y$ | 斩草除根 $x$ |
| $p$ 的归属 | $p = p(x)$ | $p = p(y)$ |
| $y''$ 写法 | $p'$ | $p\,\dfrac{\mathrm{d}p}{\mathrm{d}y}$ |
| 一阶方程自变量 | $x$ | $y$ |

## §3 二阶常系数线性微分方程求通解 

### §3.1 齐次: $y'' + py' + qy = 0$

**核心方法**:**特征方程法**(令 $y = e^{rx}$ 代入)

| 步骤 | 动作 |
|---|---|
| ① | 写特征方程:$r^2 + pr + q = 0$ |
| ② | 解特征根(判别式 $\Delta = p^2 - 4q$) |
| ③ | 按 $\Delta$ 三种情形写通解(见下表) |

**三种根的情形**(必背):

| $\Delta = p^2-4q$ | 特征根 | 通解 |
|---|---|---|
| $\Delta > 0$ | 两个不等实根 $r_1\ne r_2$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| $\Delta = 0$ | 二重根 $r_1 = r_2 = r$ | $y = (C_1 + C_2 x)\,e^{rx}$ |
| $\Delta < 0$ | 共轭复根 $\alpha\pm\beta i\ (\beta>0)$ | $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |

> 二重根必须凑 $xe^{rx}$(两 $e^{rx}$ 比值 $= 1$ 常数,线性相关)
> 复根用欧拉公式:$\mathrm{e}^{(\alpha+\beta i)x} = \mathrm{e}^{\alpha x}(\cos\beta x + i\sin\beta x)$,取实部虚部

### §3.2 非齐次: $y'' + py' + qy = f(x)$ 

**核心结论**:**通解 = 齐通解 + 非齐特解**(解的结构)

$$\boxed{y = \underbrace{C_1 y_1(x) + C_2 y_2(x)}_{\text{齐通解}} + \underbrace{y^*(x)}_{\text{非齐特解}}}$$

**步骤**(三步走):

| 步骤 | 动作 |
|---|---|
| ① | 求齐通解:解 $y'' + py' + qy = 0$ → §3.1 套表得 $C_1 y_1 + C_2 y_2$ |
| ② | 求非齐特解 $y^*$:按 $f(x)$ 形式选方法 → 见 §3.3 / §3.4 |
| ③ | 合并:通解 = 齐通解 + 非齐特解 |

**解的三个性质**(作客观题用):

| 性质 | 结论 |
|---|---|
| 自由项可加性 | $f_1 \to y_1^*,\ f_2\to y_2^*$,则 $y_1^*+y_2^*$ 是 $f_1+f_2$ 的特解 |
| 特解之差 = 齐次解 | $y_1^* - y_2^*$ 是对应齐次方程的解 |

### §3.3 非齐特解 · 待定系数法 

**类型 ①** $f(x) = P_n(x)\,e^{\alpha x}$:

$$\boxed{y^* = e^{\alpha x}\,Q_n(x)\,x^k}$$

**类型 ②** $f(x) = e^{\alpha x}[P_m(x)\cos\beta x + P_n(x)\sin\beta x]$:

$$\boxed{y^* = e^{\alpha x}\!\left[Q_l^{(1)}(x)\cos\beta x + Q_l^{(2)}(x)\sin\beta x\right]x^k}$$

**口诀:一看二算三比较**(6 步走):

| 步骤 | 动作 |
|---|---|
| ① 一看 | 看自由项中的 $\alpha$ / $(\alpha\pm\beta i)$ |
| ② 二算 | 算特征根 $r_{1,2}$ |
| ③ 三比较 | $\alpha$ (或 $\alpha\pm\beta i$) 与 $r_{1,2}$ 的**相等个数** → 定 $k$ |
| ④ | 写出 $y^*$ 待定形式($Q_n$ / $Q_l^{(1)}, Q_l^{(2)}$ 必须按 $n$ 次一般多项式**写全**,即使原式缺项) |
| ⑤ | 求导代入原方程,比较同类项系数,解出待定系数 |
| ⑥ | 写出 $y^*$ |

**$k$ 的取值规则**(类型 ①):

| $\alpha$ 与特征根关系 | $k$ |
|---|---|
| $\alpha$ 不是特征根 | $0$ |
| $\alpha$ 是单特征根 | $1$ |
| $\alpha$ 是二重特征根 | $2$ |

**$k$ 的取值规则**(类型 ②):只可能 $k=0$ 或 $k=1$
- $\alpha\pm\beta i$ 不是特征根 → $k=0$
- $\alpha\pm\beta i$ 是特征根 → $k=1$

**$l$ 的取值**:$l = \max\{m, n\}$(取 $m,n$ 较大者)

### §3.4 非齐特解 · Heaviside 微分算子法(客观题加速)

**约定**:
- $D = \dfrac{\mathrm{d}}{\mathrm{d}x}$
- $y'' + py' + qy = f(x)$ → $(D^2+pD+q)y = f(x)$,记 $F(D) = D^2+pD+q$
- $y^* = \dfrac{1}{F(D)}\,f(x)$
- $\dfrac{1}{D}$ 表示积分(常数 $= 0$)

| 自由项类型 | 公式 |
|---|---|
| $\mathrm{e}^{\alpha x}$ | $y^* = \dfrac{1}{F(D)}\!\Big\vert_{D=\alpha}\,\mathrm{e}^{\alpha x}$(若 $=0$ 补 $x$,再 $=0$ 补 $x^2$) |
| $\cos\beta x$ / $\sin\beta x$ (a: $F=D^2+q$) | $D=\beta i$ 代入,$=0$ 时求导 $(2D)$ **不代值** |
| $\cos\beta x$ / $\sin\beta x$ (b: $F=D^2+pD+q$) | 把 $D^2=-\beta^2$ 代入(**只带 $D^2$, 不带 $D$**),上下乘共轭消 $D$ |
| $k$ 次多项式 | 把 $\dfrac{1}{F(D)}$ 写成 $\dfrac{1}{1-x}$ 形式 **泰勒展开** 到 $k$ 次为止($k+1$ 次导归零停) |
| $\mathrm{e}^{\alpha x}v(x)$ | 先挪 $\mathrm{e}^{\alpha x}$ 到外 → $D \to D+\alpha$(平移) → 化简后按上面套路 |

> ⚠️ **Heaviside 不是大题标准答案**,只是客观题加速 / 快速检验。大题以**待定系数法**为标准答案。

## §4 $n>2$ 阶常系数齐次线性方程求通解 

> 老王:"一般都不可能这样考的,三阶、四阶都有可能,到 5 阶就太过分了"

**通解结构**(4 种根-通解对应):

| 情形 | 根 | 通解含 |
|---|---|---|
| ① 单实根 $r$ | $r$ 出现 1 次 | $C\,e^{rx}$ |
| ② $k$ 重实根 $r$ | $r$ 出现 $k$ 次 | $(C_1 + C_2 x + \dots + C_k x^{k-1})\,e^{rx}$ |
| ③ 单复根 $\alpha\pm\beta i$ | 出现 1 次 | $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |
| ④ 二重复根 $\alpha\pm\beta i$ | 出现 2 次 | $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x + C_3 x\cos\beta x + C_4 x\sin\beta x)$ |

> 老王原话"四都不可能考,你只要把 1、2、3 记住就行了";共轭复根**必须成对**出现

**求通解步骤**:

| 步骤 | 动作 |
|---|---|
| ① | 写特征方程 $r^n + a_{n-1}r^{n-1} + \dots + a_0 = 0$ |
| ② | 解特征根(求所有根,按重数记) |
| ③ | 按 4 种情形对号入座,把所有项加起来得通解 |

## §5 反求方程(给特解反求参数 / 反求方程) 

### §5.1 反求方程的理论基础 — 4 条注(必背)

| 注 | 解中含 | 反推 |
|---|---|---|
| (1) | $e^{rx}$ | $r$ **至少**为单实根 |
| (2) | $x^{k-1}\,e^{rx}$ | $r$ **至少**为 $k$ 重实根 |
| (3) | $e^{\alpha x}\cos\beta x$ 或 $e^{\alpha x}\sin\beta x$ | $\alpha\pm\beta i$ **至少**为单复根 |
| (4) | $e^{\alpha x}x\cos\beta x$ 或 $e^{\alpha x}x\sin\beta x$ | $\alpha\pm\beta i$ **至少**为二重复根 |

> 为什么是"至少"不是"恰好"?—— 因式分解得到的因式不代表只有这个因式。实战意义: 数清总阶数 vs 已占阶数,**填满了才能锁定"恰好"**。

### §5.2 反求方程步骤(给解反求方程) 

| 步骤 | 动作 |
|---|---|
| ① | 看解的形式:找 $e^{rx}$ / $e^{\alpha x}\cos\beta x$ / $x\,e^{rx}$ / $e^{\alpha x}x\cos\beta x$ |
| ② | 用 4 条注 → 反推根的"至少"性质 |
| ③ | 数清总阶数:已占阶数 vs 方程阶数,看是否"恰好" |
| ④ | 写特征方程(因式相乘 → 展开) → 写微分方程 |

> 例: $y_1 = e^x\cos 2x$, $y_2 = x$,方程是 4 阶,$y^{(4)}$ 前系数为 1 → $1\pm 2i$(共轭),$0$ 至少二重根 → 已占满 4 个 → 4 个根恰好是 $1+2i, 1-2i, 0, 0$ → 特征方程 $(r^2-2r+5)r^2 = 0$ → $y^{(4)}-2y''' + 5y'' = 0$ ✓

### §5.3 反求方程参数(给特解反求 $\alpha, \beta, \gamma$)

> 老王三步口诀

| 步骤 | 动作 |
|---|---|
| ① | 看自由项: 凡是 $e^{\alpha x}$ 中 $\alpha$ 不在自由项 $\alpha$ 集合里的 → 一定**不是**非齐特解 → 归齐次 |
| ② | 假设剩余部分是非齐特解,推导是否跟齐次部分矛盾(假设-反证)→ 推出齐次 |
| ③ | 把确认为非齐特解的部分代入原方程,定参数 |

> 例: $y^* = e^{2x} + (1+x)e^x$,自由项 $\gamma e^x$
> - $e^{2x}$ 的 $\alpha=2\ne 1$ → 归齐次
> - 假设 $e^x$ 是非齐特解 → 则 $xe^x$ 是齐次解 → $r=1$ 至少二重根 → 与 $r=2$ 矛盾(二阶最多 2 根) → 所以 $e^x$ 也是齐次解
> - 把 $y^* = xe^x$ 代入原方程 → 定 $\gamma$

## §6 欧拉方程(数一专属,讲课稿明确要考) 

> ⚠️ **考纲声明**(教材 + 讲课稿双标记):
> - 教材严格写"**数学二、数学三的考纲中不要求掌握欧拉方程**"
> - 但讲课稿第 1 句: **"这就是数二数三一定要看"**"这就是数学二的大题"
> - 备考处理: **数一按考纲要求;数二数三按讲课稿指示**(历年真题出现过)

### §6.1 判别

**形状**:形如
$$x^2\,y'' + pxy' + qy = f(x)$$
其中 $p, q$ 为常数。

**判别特征**:**$y$ 的导数阶数 = 前面 $x$ 的次数**
- $y''$ 前面是 $x^2$
- $y'$ 前面是 $x^1$
- $y$ 前面是 $x^0$

满足 = 欧拉方程;不满足不算。

### §6.2 求解步骤(#六步走)

> 老王总结: "微分方程的关键是要引入一个换元,通过换元把方程化简化"

| 步骤 | 动作 | 关键公式 |
|---|---|---|
| ① | 识别方程类型 | 阶数 ↔ 次数对应 |
| ② | 令 $x = e^t$($t = \ln x$) | 适用于 $x > 0$;$x < 0$ 用 $x = -e^t$ |
| ③ | 链式法则 + 乘积求导 | 把 $y'$, $y''$ 用 $\dfrac{\mathrm{d}y}{\mathrm{d}t}$, $\dfrac{\mathrm{d}^2 y}{\mathrm{d}t^2}$ 表示 |
| ④ | 代入原方程,合并 | 乘 $x^2$ 后 $x$ 全约掉,**化为常系数** |
| ⑤ | 求解常系数方程 | 特征根 / 待定 / 算子法 → 回到 §3 套路 |
| ⑥ | 回代 $t = \ln x$ | $\mathrm{e}^{-t}=1/x$,$\mathrm{e}^{-2t}=1/x^2$ 等 |

### §6.3 换元的两个核心公式(必背)

**一阶导**:
$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{1}{x}\cdot\frac{\mathrm{d}y}{\mathrm{d}t}$$

**二阶导**:
$$\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} = \frac{1}{x^2}\!\left(\frac{\mathrm{d}^2 y}{\mathrm{d}t^2} - \frac{\mathrm{d}y}{\mathrm{d}t}\right)$$

**乘 $x^2$ 后的欧拉方程**:
$$\boxed{\frac{\mathrm{d}^2 y}{\mathrm{d}t^2} + (p-1)\frac{\mathrm{d}y}{\mathrm{d}t} + qy = f(e^t)}$$

> ⚠️ **系数变化规律**:
> - $y''$ 系数 $1$ → $1$(不动)
> - $y'$ 系数 $p$ → $p-1$ (**$-1$!**)
> - $y$ 系数 $q$ → $q$(不动)
> - 右端 $f(x)$ → $f(e^t)$(**别忘了换**)

> ⚠️ **致命坑**:
> 1. **回代忘了换**:$y = C_1 e^{-t} + C_2 e^{-2t}$ 直接交卷 → 0 分。必须 $t = \ln x$ 换回 $y(x)$ → $y = C_1/x + C_2/x^2$
> 2. **$(p-1)$ 写成 $p$**
> 3. **特征根符号写错**:例 $r_1=-1, r_2=-2$,不是 $1, 2$
> 4. **不识别欧拉方程**,以为是"乱七八糟的方程"放弃 → 实际 2 分钟送分

## §7 找特解三步走的填空模板(背下来就完事)

对于二阶常系数非齐次方程,不论用待定系数法还是 Heaviside,**核心 6 步永远不变**:

```
① 一看  → 自由项中的 α (或 α±βi)
② 二算  → 特征根 r₁, r₂
③ 三比较 → ① 与 ② 的相等个数,定 k
④ 写出 y* 的待定形式(Q_n / Q_l⁽¹⁾, Q_l⁽²⁾ 写全)
⑤ 求导代入,比较系数,解出待定系数
⑥ 写 y*
⑦ 合并: y = 齐通解 + y*
```

## §8 雷区速查(考场前必扫一眼)

| # | 坑 | 后果 | 防范 |
|---|---|---|---|
| 1 | 分离变量时多除一项 | 加 $g(y)\ne 0$ 约束,丢奇解 | 考研只求通解,不补 → 默认丢;若要全解,代回原方程验证 |
| 2 | 换元 $u=ax+by+c$ 后忘了换回 | 0 分 | 写完通解代特殊值验 |
| 3 | 一阶线性公式内部 $\int$ 加 $C$ | 多常数 / 错 | 两个 $\int$ 都不加 $C$,整体加一个 |
| 4 | 讨论解性质用不定积分写法 | 写不出具体 $x$ 值 | 极限 / 周期 / 有界 → 必用变限积分 |
| 5 | 切线截距字母重复 | 与 $P(x,y)$ 冲突 | 切线动点用 $X, Y$ |
| 6 | "齐次型" 当 "齐次方程" | 解法错 | 齐次型 = 右端只含 $y/x$;齐次方程 = $f(x)\equiv 0$ |
| 7 | 二阶可降阶类型(2)$y''$ 写 $p'$ | 混进 $x$,新增复杂性 | 必须写 $p\cdot\dfrac{\mathrm{d}p}{\mathrm{d}y}$ |
| 8 | 二阶可降阶类型(1)/(2) $p$ 自变量搞混 | 解错 | 类型(1)$p=p(x)$,类型(2)$p=p(y)$ |
| 9 | 二阶常系数齐次二重根漏凑 $xe^{rx}$ | 线性相关,不算通解 | 二重根必须 $(C_1+C_2 x)e^{rx}$ |
| 10 | 待定系数 $Q_n(x)$ 漏写项 | 系数解不出来 | $Q_n$ 必须按 $n$ 次一般多项式**写全** |
| 11 | Heaviside 求导后代 $D=\beta i$ | 错(应不代值) | 类型②a 求导后**不代值**,直接用 $2D$ 等 |
| 12 | Heaviside 类型②b 同时代 $D^2$ 和 $D$ | 错 | **只带 $D^2$,不带 $D$** |
| 13 | Heaviside 类型④忘平移 | 错 | 先挪 $\mathrm{e}^{\alpha x}$ 到外,再 $D\to D+\alpha$ |
| 14 | 欧拉回代忘换 | 0 分 | $y = C_1 e^{-t}+\dots$ **必须**换回 $y(x)$ |
| 15 | 欧拉 $(p-1)$ 写成 $p$ | 错 | $y'$ 系数 $p-1$,**不是 $p$** |
| 16 | 反求方程数阶数 | 漏根 / 多根 | 数清已占 vs 总阶数,填满才"恰好" |
| 17 | 例 15.18 反求假设跳步 | 绕不出弯 | 老王三步:看自由项 → 假设-反证 → 代入定参数 |
| 18 | 通解常数取值范围 | 错 | 例 15.4 $C>1$,**回代**原方程验证 |
