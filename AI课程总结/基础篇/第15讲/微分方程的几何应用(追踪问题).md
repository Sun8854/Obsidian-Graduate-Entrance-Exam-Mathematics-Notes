## 一、为什么"追踪问题"能写微分方程

### 1. 几何直觉:切线 = 此刻运动方向

**老王原话**(讲课稿第 1 段):"1 条曲线在一点处的切线, 其实你从这个几何上来说, 你不仅知道它是切线, 还要知道这个切线的方向. 这就是代表这个切线的这个线的这个方向向量. 它实际上就是代表这一时刻这个支点它的运动方向."

> [!tip] 一句话迁移
> 曲线上**点 + 切线方向 = 此刻在动**. 知道"在哪 + 往哪走" = 拿到了运动方程的导数信息, 就能反求轨迹.

### 2. 引入情境:达·芬奇自行车 + 福尔摩斯断案

**教材 page 1** 给了三张图(教材扫描 PDF 397 页):

- **图 15-1**: 达·芬奇当年画的自行车草图 —— 跟现代自行车几乎无异
- **图 15-2**: 大雨后泥泞路上留下的 **$L_1, L_2$ 两条轨迹**
- **图 15-3**: 两条轨迹上各有 $A, B, C, D$ 几个采样点, 上面那条是 $L_2$, 下面那条是 $L_1$(实线 = 后轮轨迹, 虚线 = 切线方向)

「避坑 · 哪个是前轮、哪个是后轮」

- **老王原话**:"前轮是无拘无束的, 它是引导者, 它不跟着后轮走, 是后轮跟着前轮走"
- **判定方法**:轨迹上某点 $A$ 的切线, **若不与另一条曲线相交** → 这条是**前轮**轨迹(前轮方向不依赖后轮),**反之**是**后轮**轨迹
- 教材 page 1 结论:"那么 $L_2$ 是前轮轨迹, $L_1$ 是后轮轨迹"

> **车向左还是向右?**(教材 page 1 + 老王口述)
> - 看图 15-3: 同一时刻后轮 $B_1$ / $B_2$ 到前轮 $D_1$ / $D_2$ 的距离, **都必须 = 车梁长度 $L$**
> - 教材 page 1 测量: $\lvert B_2 C_2 \rvert \neq \lvert B_1 D_1 \rvert$ → 车不可能向右行驶 → 自右向左行驶
> - **秒杀要点**: **不需要量绝对值, 量"不同点处的梁长是不是同一个数"** —— 不一致 = 方向错

## 二、追踪问题建模:两条方程联立

### 1. 抽象成数学题 —— 例 15.21

**教材 page 1 末 → page 2 全文** = 例 15.21 全题:

> [!quote] 例 15.21 (教材 PDF 397-398)
> 设自行车前轮和后轮与地面的接触点分别为 $P$ 和 $Q$, 并设 $\lvert PQ \rvert = 1$, 初始时刻 $P$ 在原点, $Q$ 在 $(1, 0)$ 点, 若**前轮沿 $y$ 轴的正方向前进**, 求 $Q$ 点的运动轨迹.

「避坑 · 初始位置」

- $P$ 在原点 $(0, 0)$, 沿 $y$ 轴正方向走 → $P$ 一直都在 $y$ 轴上
- $Q$ 在 $(1, 0)$ → 初始时 $Q$ 离 $P$ 距离 = 1(车梁)
- **初值**: $x = 1, y = 0$ 时启动 $Q$ 轨迹

### 2. 方程 ①:距离不变(几何方程)

**老王原话**(讲课稿第 5 段):"P 点的坐标在任意位置的时候, 我们把它写成 $(0, Y)$ 对吧? 因为它的这个横坐标始终是零, 那么纵坐标写成 $Y$, 那么 Q 那么这个 Q 点的话, 我们就是坐标是 $(x, y)$ 了"

**(教材 page 2 第 1 步)** $\lvert PQ \rvert = 1$ 翻译成:

$$x^2 + (y - Y)^2 = 1 \quad \implies \quad y - Y = \pm\sqrt{1 - x^2}$$

「避坑 · $y - Y$ 取正还是取负」

- **教材 page 2 红字批注**:"$Y > y$, 故取负值"
- **老王原话**:"横坐标始终是零, 纵坐标是 $Y$" + Q 在第二象限滑过来, $y < Y$, 所以 $y - Y < 0$
- **铁律**: 取 $\sqrt{\cdot}$ 之前**一定看图判方向**, 别无脑取正

$$\boxed{y - Y = -\sqrt{1 - x^2}}$$

### 3. 方程 ②:切线方向 = 此刻指向目标(微分方程)

**老王原话核心**(讲课稿第 5 段末 + 第 6 段首):"后轮的这个点, 在任意时刻它的切线方向画 1 条切线, 一定是**指向前轮此刻所在的那个点**"

「秒杀 · 翻译成导数」

**斜率 = 纵坐标差 / 横坐标差**(就是 $\tan\theta$, $\theta$ = 切线方向与 $x$ 轴正方向夹角):

$$\frac{dy}{dx} = \frac{y - Y}{x - 0} = \frac{y - Y}{x}$$

代入 $y - Y = -\sqrt{1 - x^2}$:

$$\boxed{\frac{dy}{dx} = -\frac{\sqrt{1 - x^2}}{x}}$$

> [!tip] 通用建模口诀(借鉴第 3 讲切线知识)
> - **"B 始终盯着 A"** → B 那点的切线斜率 = $\dfrac{y_B - y_A}{x_B - x_A}$
> - 距离不变 → 另一个代数方程
> - 两条方程联立 → 变量可分离 → 求解

## 三、求解追踪曲线(令 $x = \sin t$)

### 1. 变形为积分

**教材 PDF 398 页** 步骤:

$$y = -\int \frac{\sqrt{1 - x^2}}{x} \, dx$$

### 2. 换元 $x = \sin t$

**(教材 page 2 第 2 块)** 令 $x = \sin t$, 于是 $\sqrt{1 - x^2} = \cos t$, $dx = \cos t \, dt$:

$$y = -\int \frac{\cos^2 t}{\sin t} \, dt = -\int \frac{1 - \sin^2 t}{\sin t} \, dt$$

拆成两项:

$$y = -\int \csc t \, dt + \int \sin t \, dt$$

### 3. 两块分别积

**(a) $\int \sin t \, dt = -\cos t + C$** —— 一眼就会

**(b) $\int \csc t \, dt$ 怎么办?**

$$\csc t = \frac{1}{\sin t} = \frac{1}{2 \sin\frac{t}{2} \cos\frac{t}{2}} \cdot \frac{2\sin^2\frac{t}{2}}{\sin\frac{t}{2} \cdot \sin\frac{t}{2}} \cdot \cdots$$

**教材 page 2 右侧红字批注** 给的速写:

$$\int \frac{dt}{\sin t} = \int \frac{dt}{2\sin\frac{t}{2}\cos\frac{t}{2}} = \int \frac{d\left(\tan\frac{t}{2}\right)}{\tan\frac{t}{2}} = \ln\left\lvert\tan\frac{t}{2}\right\rvert + C$$

「避坑 · 备选: $\csc t = \csc t - \cot t + \cot t$ 凑微分法」

$$\int \csc t \, dt = \int \frac{\csc t (\csc t - \cot t)}{\csc t - \cot t} \, dt = -\ln\lvert\csc t - \cot t\rvert + C$$

> 两种方法等价($\ln\lvert\tan\frac{t}{2}\rvert = -\ln\lvert\csc t - \cot t\rvert$),**记住任一种**即可。

### 4. 把 $t$ 还原回 $x$

**(教材 page 2 第 3 块)** 用 **半角公式** $+\csc t = \dfrac{1}{\sin t}$ $+\cot t = \dfrac{\cos t}{\sin t}$ 还原:

$$\csc t = \frac{1}{x}, \quad \cot t = \frac{\sqrt{1-x^2}}{x} \quad (\text{因为 } t \in (0, \tfrac{\pi}{2}), \cos t > 0, \text{ 故 } \sqrt{1-x^2} \text{ 不取负})$$

「避坑 · 符号判定」

- $x = \sin t \in (0, 1]$, $t \in (0, \tfrac{\pi}{2}]$
- $\cos t = \sqrt{1 - x^2}$, **取正** 不带负号
- $\cot t = \dfrac{\cos t}{\sin t} = \dfrac{\sqrt{1-x^2}}{x}$

代入:

$$y = -\left(-\ln\lvert\csc t - \cot t\rvert\right) - \cos t + C = \ln\left\lvert\frac{1}{x} - \frac{\sqrt{1-x^2}}{x}\right| - \sqrt{1-x^2} + C$$

**变号**(分子分母互换)取对数变负:

$$y = \ln\left\lvert\frac{1}{x} + \frac{\sqrt{1-x^2}}{x}\right| - \sqrt{1-x^2} + C = \ln\frac{1 + \sqrt{1-x^2}}{x} - \sqrt{1-x^2} + C$$

### 5. 用初始条件定 $C$

**(教材 page 2 末)** 由 $x = 1, y = 0$:

$$0 = \ln\frac{1 + 0}{1} - 0 + C = \ln 1 + C = C \quad \implies \quad C = 0$$

### 6. 最终轨迹方程

$$\boxed{y = \ln\frac{1 + \sqrt{1-x^2}}{x} - \sqrt{1-x^2}}$$

**几何意义**(图 15-4): $Q$ 从 $(1, 0)$ 出发, $y$ 先升后降, 趋近原点 $(0, 0)$ 但**永远到不了** —— 经典追线曲线(tracks curve)。

## 五、本节方法论总结(老王口述 + 教材双源)

### 1. 核心建模步骤(4 步走, 直接背)

| 步骤 | 任务 | 公式 / 动作 |

| ① | 看图判前后轮 | 切线方向不指向另一条轨迹 = 前轮 |

| ④ | 变量可分离 + 换元 $x = \sin t$ 积分 | 见 §三 |

### 2. 应用题难点:翻译

**老王原话**(讲课稿第 7 段):"应用题难点在于把题目的说的话翻译成数学表达式 ... 这种题为什么得分率极低? 主要是大家对于这个实际问题当中的关键信息没有把握住, 没有翻译出来"

> [!tip] 给学生的实操建议
> - 任何"追 / 盯 / 始终朝向" 类应用题, **第一步先画图标坐标 + 标距离 $L$**
> - 第二步把"始终朝向"翻译成 $\tan\theta = \dfrac{\Delta y}{\Delta x}$
> - 第三步把"距离不变"翻译成代数方程
> - **两条方程都出来了, 剩下就是积分**

### 3. 跨题型答题套路

| 题干关键词 | 翻译后 |
|-----------|-------|
| "始终盯着 A / 永远朝向 A" | 曲线在 B 点的切线 $\to$ A 点 |
| "距离恒为 $L$" | $\lvert AB \rvert = L$ 几何方程 |
| "导弹追目标" / "响尾蛇导弹"(1993 真题) | 同上套路, 区别只是坐标系 |
| "前轮沿轴正方向" | 一个坐标恒为 0 |
