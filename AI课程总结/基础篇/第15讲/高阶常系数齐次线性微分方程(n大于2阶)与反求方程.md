## 一、例 15.17 · $y''-3y'+2y=2\mathrm{e}^{-x}\cos x$ 的通解(待定系数法 vs Heaviside 算子法) #必考

> 求 $y'' - 3y' + 2y = 2\mathrm{e}^{-x}\cos x$ 的通解.(教材 full.md:49)

### 1. 第 1 步:求齐次方程的通解

**特征方程**:$r^2 - 3r + 2 = 0$

**特征根**:$r_1 = 1, r_2 = 2$ (两个不等实根)

**齐通解**:
$$\overline{y} = C_1\mathrm{e}^x + C_2\mathrm{e}^{2x}$$

### 2. 第 2 步:求非齐次方程的特解 — **方法一 · 待定系数法**

**特解形式**(教材 full.md:61):

自由项 $f(x) = 2\mathrm{e}^{-x}\cos x$,属于"$\mathrm{e}^{\alpha x}[P_m\cos\beta x + P_n\sin\beta x]$"型 ($\alpha=-1,\ \beta=1,\ m=n=0$),所以设:
$$y^* = \mathrm{e}^{-x}(A\cos x + B\sin x)$$

**待定系数计算**(教材 full.md:64-71):

$$y^{*\prime} = \mathrm{e}^{-x}[(B-A)\cos x - (A+B)\sin x]$$
$$y^{*\prime\prime} = \mathrm{e}^{-x}(-2B\cos x + 2A\sin x)$$

代入原方程,比较系数解得 $A = \dfrac{1}{5},\ B = -\dfrac{1}{5}$,即

$$\boxed{y^* = \frac{\mathrm{e}^{-x}}{5}(\cos x - \sin x)}$$

### 3. 第 2 步:求非齐次方程的特解 — **方法二 · Heaviside 微分算子法**

**算子写法**:
$$y^* = \frac{1}{D^2-3D+2}\cdot 2\mathrm{e}^{-x}\cos x$$

**操作步骤**(教材 full.md:74-77):

1. 把 $\mathrm{e}^{-x}$ 挪到算子外面,$D \to D-1$(平移):
$$y^* = 2\mathrm{e}^{-x}\cdot\frac{1}{(D-1)^2 - 3(D-1) + 2}\cos x$$

2. 展开算子:$(D-1)^2 - 3(D-1) + 2 = D^2 - 5D + 6$

3. 把 $D^2 = -1$ 代入:$-5D + 5$,提出 $-5$:$\dfrac{1}{-5D+5} = -\dfrac{1}{5}\cdot\dfrac{1}{D-1}$

4. 上下乘共轭 $D+1$:$\dfrac{D+1}{D^2-1}$,把 $D^2 = -1$ 代入得 $-2$

5. 汇总:
$$y^* = -\frac{2}{5}\mathrm{e}^{-x}\cdot\frac{D+1}{-2}\cos x = \frac{1}{5}\mathrm{e}^{-x}(D+1)\cos x$$

6. 算 $D\cos x = -\sin x$:$y^* = \dfrac{1}{5}\mathrm{e}^{-x}(-\sin x + \cos x)$ ✓ 跟待定系数法一致

### 4. 第 3 步:写出通解

$$\boxed{y = C_1\mathrm{e}^x + C_2\mathrm{e}^{2x} + \frac{\mathrm{e}^{-x}}{5}(\cos x - \sin x)}$$

> 「避坑 · 教材原话(导出页面自 305-478.md:87)」"待定系数法易设出形式,难点在于计算量大,建议考生作为练习尝试书写过程. **微分算子法计算量较小,难点在于需记住大量形式**."

「老王评价」"考研的标准答案里面也主要是待定系数法,但微分算子法可以用作快速的检验,或者说作为这个客观题,用它可能稍微会快一些,但是需要你记一些规则."

## 二、例 15.18 · 反求方程参数 + 写出通解 #必考 #困难

> 设二阶常系数线性微分方程 $y'' + \alpha y' + \beta y = \gamma\mathrm{e}^x$ 的一个特解为 $y^* = \mathrm{e}^{2x} + (1+x)\mathrm{e}^x$. 确定常数 $\alpha, \beta, \gamma$,并求该方程的通解.(教材 full.md:89)

> [!warning] 「命题方向 audit · 这是必考难点题」
> **反的什么?不是反最终结论,而是反 "已知特解 $y^*$ = 齐次 + 非齐" 这个**中间拆分思路**.**
> 老王反复强调(讲课稿):"否则的话就是你如果反复的只是听这个,你可能搞不明白,就是你没绕不出来有可能?"
>
> 三段判定:
> 1. **最终结论**(教材定理): 齐通解 + 非齐特解 = 非齐通解(上一节讲过的解的结构)
> 2. **中间命题**(本例): 给定一个解 $y^* = \mathrm{e}^{2x} + (1+x)\mathrm{e}^x = \mathrm{e}^{2x} + \mathrm{e}^x + x\mathrm{e}^x$,判断其中哪些部分是齐次解、哪些是非齐特解
> 3. **两者区别**: 不是反结论,是**拆分技巧**

### 1. 第 1 步:拆分 $y^*$,标定齐次 vs 非齐部分

**关键拆分**(教材 full.md:91, 老王原话):

$$y^* = \mathrm{e}^{2x} + \mathrm{e}^x + x\mathrm{e}^x$$

**判定流程**(老王口述,教材 full.md:91-95):

```
① 首先看 自由项 = γ e^x
   → e^(αx) 中 α ≠ 1 的部分不可能是非齐次方程的特解
   → 所以 e^(2x) 不可能是非齐次特解,只能是齐次方程的特解

② 那么 e^x 是齐次还是非齐?
   → 假设 e^x 是非齐次方程的特解
   → 那么 x·e^x 就是齐次方程的特解
   → 这意味着 r = 1 至少是二重根
   → 但 e^(2x) 是齐次方程的特解,意味着 r = 2 也是根
   → 二阶方程最多 2 个根,矛盾!
   → 所以 e^x 也不是非齐次方程的特解

③ 结论: e^x 是齐次方程的特解
   → 此时 r₁ = 2, r₂ = 1 都是齐次方程的特征根
```

### 2. 第 2 步:写出特征方程

由 $r_1 = 2,\ r_2 = 1$:
$$(r-1)(r-2) = r^2 - 3r + 2 = 0$$

对比 $y'' + \alpha y' + \beta y = \gamma\mathrm{e}^x$,得

$$\boxed{\alpha = -3, \quad \beta = 2}$$

### 3. 第 3 步:代入求 $\gamma$

非齐次方程是 $y'' - 3y' + 2y = \gamma\mathrm{e}^x$,把 $x\mathrm{e}^x$(非齐特解)代入:

$$(x+2)\mathrm{e}^x - 3(x+1)\mathrm{e}^x + 2x\mathrm{e}^x = \gamma\mathrm{e}^x$$

化简:
$$[(x+2) - 3(x+1) + 2x]\mathrm{e}^x = \gamma\mathrm{e}^x$$
$$[x + 2 - 3x - 3 + 2x]\mathrm{e}^x = \gamma\mathrm{e}^x$$
$$-\mathrm{e}^x = \gamma\mathrm{e}^x$$

所以 $\boxed{\gamma = -1}$

### 4. 第 4 步:写出原方程的通解

原方程为 $y'' - 3y' + 2y = -\mathrm{e}^x$,通解为:

$$\boxed{y = C_1\mathrm{e}^x + C_2\mathrm{e}^{2x} + x\mathrm{e}^x}$$

> 「避坑 · 老王强调验证」(讲课稿)"大家可以拿着这个正向的再走一遍. 你再回头来重新听一下我对这个的分析,你就明白了."
>
> **验证动作**: 把 $\alpha=-3, \beta=2, \gamma=-1$ 代回原方程,确认 $y^* = x\mathrm{e}^x$ 确实是非齐次特解.

> 「秒杀技巧 · 老王三步口诀」(讲课稿总结)
> 1. **第一步**: 看自由项,凡是 $\mathrm{e}^{\alpha x}$ 中 $\alpha$ 不在自由项 $\alpha$ 集合里的,一定不是非齐特解 → 归齐次
> 2. **第二步**: 假设剩余部分是非齐特解,推导是否跟齐次部分矛盾 → 推出齐次
> 3. **第三步**: 把确认为非齐特解的部分代入原方程,定参数

## 三、$n(n>2)$ 阶常系数齐次线性微分方程 — 通解结构 #必考

> 老王:"这个一般都不可能这样考的. ... 一般到几阶呢?三阶、四阶都有可能,到 5 阶就太过分了."

### 1. 通解的 4 种"根-通解"对应关系

> 教材原话(导出页面自 305-478.md:113-137),4 种情形对应通解:

**情形 ① · 单实根 $r$**
$$\text{通解含一项}\ C\mathrm{e}^{rx}$$

**情形 ② · $k$ 重实根 $r$**
$$\text{通解含}\ (C_1 + C_2 x + C_3 x^2 + \dots + C_k x^{k-1})\mathrm{e}^{rx}$$

> 老王原话:"如果是二重根的话, 我就 $C_1 + C_2 x$ 乘 $\mathrm{e}^{rx}$; 如果是三重根, 不就 $C_1 + C_2 x + C_3 x^2$ 乘 $\mathrm{e}^x$. ... 你不可能再往下写了. **实际上是 $C_k x^{k-1}$ 乘 $\mathrm{e}^{rx}$, 你是几重根, 你就写出 $C$ 几, 然后乘上 $x$ 的这个重根个数减一次方, 这个就可以了.**"

**情形 ③ · 单复根 $\alpha\pm\beta i$**
$$\text{通解含}\ \mathrm{e}^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$$

**情形 ④ · 二重复根 $\alpha\pm\beta i$**(教材 full.md:135-137)
$$\text{通解含}\ \mathrm{e}^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x + C_3 x\cos\beta x + C_4 x\sin\beta x)$$

> 「避坑 · 老王口诀」(讲课稿)
> - ①② 单实根 / k 重实根 — **背下来**
> - ③ 单复根 — **必背**(跟二阶一样)
> - ④ 二重复根 — **建议背**(胆子大可以不记)
>
> 老王原话:"其实我告诉你四都不可能考的,是吧, 四都不可能考, 你只要把前面的这个 1 2 3 记住就行了. ... 虽然你要是胆子大一点, 我觉得这个二也不要记, 你写个三就行了."

### 2. 反求方程的理论基础 — 4 条 #重要 #必考 

> 教材 full.md:139-145 给出 4 条注,这是**反求方程**的"翻译规则":看到解的形式 → 反推根的性质 → 写特征方程.

| 注       | 解中含什么                                                                     | 反推什么                               | 教材表述        |
| ------- | ------------------------------------------------------------------------- | ---------------------------------- | ----------- |
| **(1)** | $\mathrm{e}^{rx}$                                                         | $r$ **至少**为**单实根**                 | full.md:139 |
| **(2)** | $x^{k-1}\mathrm{e}^{rx}$                                                  | $r$ **至少**为 **$k$ 重实根**            | full.md:141 |
| **(3)** | $\mathrm{e}^{\alpha x}\cos\beta x$ 或 $\mathrm{e}^{\alpha x}\sin\beta x$   | $\alpha\pm\beta i$ **至少**为**单复根**  | full.md:143 |
| **(4)** | $\mathrm{e}^{\alpha x}x\cos\beta x$ 或 $\mathrm{e}^{\alpha x}x\sin\beta x$ | $\alpha\pm\beta i$ **至少**为**二重复根** | full.md:145 |

> 「避坑 · 为什么是"至少"不是"恰好"?」
> 老王原话:"从这个因式分解里面你得到的因式, 它不代表它只有这个因式. 你比方说 $r=1$, 你有一个 $r=1$ 了, 可是后面还有 $r^2 + Ar + B$. 你现在只知道 $r=1$, 不代表这里面分解不出来 $r-1$. 所以只能说**至少**明白了."
>
> **实战意义**: 解出"至少"之后,要数一下总阶数跟"已占"阶数的关系 — 如果两者相等,才能锁定"恰好".

## 四、例 15.19 · 反求四阶常系数齐次方程 #必考 #困难

> 已知某四阶常系数齐次线性微分方程有特解 $y_1(x) = \mathrm{e}^x\cos 2x$, $y_2(x) = x$, 且方程中 $y^{(4)}$ 前的系数为 1, 该方程为 \_\_\_\_.(教材 full.md:147)

### 1. 第 1 步:从已知解反推特征根性质

**已知解 1** $y_1(x) = \mathrm{e}^x\cos 2x$:

> 应用注 (3): 解中含有 $\mathrm{e}^{\alpha x}\cos\beta x$,则 $\alpha\pm\beta i$ **至少**是单复根.

这里 $\alpha = 1, \beta = 2$,所以 $1\pm 2i$ **至少**是单复根.

**已知解 2** $y_2(x) = x$:

> 注意: $x$ 本身可以写成 $x\cdot \mathrm{e}^{0\cdot x}$,即 $\alpha = 0, \beta = 0$ 的情形.

应用注 (4): 解中含有 $\mathrm{e}^{\alpha x}x\cos\beta x$ / $\mathrm{e}^{\alpha x}x\sin\beta x$,则 $\alpha\pm\beta i$ **至少**是二重复根.

这里 $\alpha = 0$,所以 $0$ **至少**是二重实根(即 $r=0$ 至少出现 2 次).

> 「避坑 · 关键辨识」(讲课稿老王)"如果你看到了 $x \cdot \mathrm{e}^{rx}$,你马上说这个零是什么?是**至少是它的二重根**出来了, $r_{3,4} = 2, 0, = 0$. 它至少是二重根,它就至少有两个零."

### 2. 第 2 步:列出 4 个根,数清总阶数

| 根 | 来源 | 个数 |
|----|------|------|
| $r_1 = 1 + 2i$ | 由 $y_1 = \mathrm{e}^x\cos 2x$ 注 (3) | 1 |
| $r_2 = 1 - 2i$ | 共轭(根必成对出现) | 1 |
| $r_3 = 0$ | 由 $y_2 = x$ 注 (4) | 至少 2 |
| $r_4 = 0$ | 同上(已"至少"2 个) | 1 |

**总阶数核算**:

- 已占位置: $1+2i, 1-2i$ 占 2 个;$0, 0$ 占 2 个 → 共占满 4 个
- 方程是 4 阶 → 没有更多位置

**结论**: 这 4 个根就是**全部**特征根,且 $0$ 恰好是二重实根.

### 3. 第 3 步:写出特征方程

$$[r - (1+2i)][r - (1-2i)] \cdot r^2 = 0$$

展开:
$$[(r-1) - 2i][(r-1) + 2i] \cdot r^2 = [(r-1)^2 + 4] \cdot r^2$$
$$= (r^2 - 2r + 1 + 4) \cdot r^2 = (r^2 - 2r + 5) \cdot r^2$$
$$= r^4 - 2r^3 + 5r^2 = 0$$

### 4. 第 4 步:写出原方程

$$\boxed{y^{(4)} - 2y^{(3)} + 5y'' = 0}$$

> 「秒杀技巧 · 反求四步」(讲课稿老王总结)
> 1. **看解的形式**: 找 $\mathrm{e}^{rx}$ / $\mathrm{e}^{\alpha x}\cos\beta x$ / $x\mathrm{e}^{rx}$ / $\mathrm{e}^{\alpha x}x\cos\beta x$
> 2. **反推根**: 用 4 条注 → 至少是什么根
> 3. **数清总阶数**: 已占阶数 vs 方程阶数,看是否"恰好"
> 4. **写特征方程**: 因式相乘 → 展开 → 写微分方程

## 五、易错提醒(踩坑汇总)

> [!warning] **核心坑 1:例 15.17 Heaviside 算子法的 5 步不能跳**
> 1. 挪 $\mathrm{e}^{\alpha x}$ 到外 2. $D \to D+\alpha$ 平移 3. 展开算子 4. $D^2 = -\beta^2$ 代入 5. 上下乘共轭消 $D$. 老王:"这个方法其实不需要记太多规则的,你只要知道特解的待定系数法的表达式,你带你去运算就行了. 哪个适合你,这个我没有办法去评价."

> [!warning] **核心坑 2:例 15.18 反求的"假设-反证"是绕弯重点**
> 老王原话:"你不能直接说 $\mathrm{e}^x$ 是非齐特解, **假设**它是,然后推出 $x\mathrm{e}^x$ 是齐次解,出现 $r=1$ 二重根与 $r=2$ 矛盾. 结论 $\mathrm{e}^x$ 也是齐次解. 这个弯绕不过来,后面通解就写不出来."

> [!warning] **核心坑 3:$n>2$ 阶齐次方程的根按重数记**
> - $k$ 重实根: 通解是 $(C_1 + C_2 x + \dots + C_k x^{k-1})\mathrm{e}^{rx}$,**不是** $\mathrm{e}^{rx}$ 单独写一遍
> - 共轭复根**必须成对**出现:看到 $1+2i$,必须同时有 $1-2i$

> [!warning] **核心坑 4:反求方程的"至少"必须数阶数**
> 不能看到解的形式就立刻"写特征方程" — 必须先看"已占位置"是否填满方程阶数. 如果没填满,要意识到**可能有更多根**没出现.

> [!warning] **核心坑 5:第 4 阶常系数齐次方程特征根最多 4 个**
> 例 15.19 是 4 阶,所以 $1+2i, 1-2i, 0, 0$ 正好占满 4 个根. 如果是 5 阶,还会有一个**没出现的根**(不能猜!),只能从根的性质再推.

> "这个对大家的这个解的结构要求是很高的,请大家认真把这个题目理解透彻."

> "你平时练的好像都会了,那些题型好像都会. 可是上了考场,你发现在考场那个 3 小时紧张的状况下,你发现很多东西全是新的. 其实不是说东西全是新的,而是说命题老师对大家的要求. ... 你抓住这个特征,你才能找到这个知识在哪个位置,找到在哪个位置,我们才能找到相应的方法,正确的方向去解决它. 你这样的话就是我无论你怎么出题,我都能够有一个正确的方向了."
