## 一、二阶常系数**齐次**线性微分方程

### 1. 概念与解的结构

**概念**(教材 full.md:35-37): 方程
$$y'' + py' + qy = 0$$
称为**二阶常系数齐次线性微分方程**, 其中 $p, q$ 为常数.

老王原话:"二阶就很简单了 $y''$ 是吧? 常系数就是 $y''$ 我们标准型一般是最高阶导数前面的系数是一, 然后剩下的 $p, q$ 都是常数, 这就叫常系数. 其次就是等号右边的自由项为零, 然后线性方程这个当然是线性组合了."

「避坑 · 关键词拆分」

| 关键词 | 含义 |
|--------|------|
| **二阶** | 最高阶导数是二阶, 即含 $y''$ |
| **常系数** | $p, q$ 都是常数 |
| **齐次** | 右端 $f(x) \equiv 0$ |
| **线性** | $y'', y', y$ 都是一次, 线性组合 |

### 2. 解的结构(线性无关 + 通解)

**线性无关判别**(教材 full.md:41): 若 $y_1(x), y_2(x)$ 是 $y''+py'+qy=0$ 的两个解, 且
$$\frac{y_1(x)}{y_2(x)} \neq C \quad (\text{常数})$$
则称 $y_1(x), y_2(x)$ 是该方程的两个**线性无关**的解.

「避坑 · 线性相关/无关的口诀」
- $\dfrac{y_1}{y_2} = C$ (常数) → **线性相关** → 两个解本质上是同一个
- $\dfrac{y_1}{y_2} \neq C$ → **线性无关** → 可以做线性组合当通解

**例子**:
- $y_1 = x\mathrm{e}^x$, $y_2 = \mathrm{e}^x$ → $\dfrac{y_1}{y_2} = x \neq C$ → **线性无关** ✓
- $y_1 = 2x\mathrm{e}^x$, $y_2 = 3x\mathrm{e}^x$ → $\dfrac{y_1}{y_2} = \dfrac{2}{3}$ 是常数 → **线性相关** ✗

**通解公式**(教材 full.md:41): #熟记 
$$y(x) = C_1 y_1(x) + C_2 y_2(x)$$

老王原话:"找到两个线性无关的解, 则线性组合为通解."

### 3. 特征方程法(必考)

**核心思想**: 令 $y = \mathrm{e}^{rx}$ 代入方程.

为什么选 $\mathrm{e}^{rx}$? 老王原话:"什么样的函数容易满足这个方程呢? 指数函数求二阶导加上它的一阶导的 $p$ 倍, 再将它自己 $q$ 倍可以等于 0. 显然可以想到."

代入后: $y' = r\mathrm{e}^{rx}$, $y'' = r^2 \mathrm{e}^{rx}$, 代回原方程:

$$\mathrm{e}^{rx}(r^2 + pr + q) = 0$$

由于 $\mathrm{e}^{rx} \neq 0$, 得到**特征方程**: #熟记 
$$\boxed{r^2 + pr + q = 0}$$ ^xusqwj

**三种根的情形**: #熟记 #必考  ^8dnjl1

| 判别式 $\Delta = p^2-4q$ | 特征根 | 通解 | 线性无关检验 |
|----|------|------|------|
| $\Delta > 0$ | 两个**不等实根** $r_1 \neq r_2$ | $y = C_1 \mathrm{e}^{r_1 x} + C_2 \mathrm{e}^{r_2 x}$ | $\dfrac{\mathrm{e}^{r_1 x}}{\mathrm{e}^{r_2 x}} = \mathrm{e}^{(r_1-r_2)x} \neq C$ ✓ |
| $\Delta = 0$ | **二重根** $r_1 = r_2 = r$ | $y = (C_1 + C_2 x)\mathrm{e}^{rx}$ | $\dfrac{\mathrm{e}^{rx}}{x\mathrm{e}^{rx}} = \dfrac{1}{x} \neq C$ ✓ |
| $\Delta < 0$ | **共轭复根** $\alpha \pm \beta i$ ($\beta > 0$) | $y = \mathrm{e}^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ | $\dfrac{\cos\beta x}{\sin\beta x} = \cot\beta x \neq C$ ✓ |

> 「易错提醒 · $\Delta = 0$ 的通解」二重根时只能找到**一个**解 $\mathrm{e}^{rx}$, 必须**凑**出第二个解 $x\mathrm{e}^{rx}$(用洛必达 / 待定法推得). 老王讲:"如果 $r_1 = r_2$, 显然这两个比值的极限是一了, 比值等于一的是个常数, 就不符合这一条了, 它是线性相关的. ... 那么用一个 $\mathrm{e}^{rx}$ 然后再用一个 $x\mathrm{e}^{rx}$ 这两个一比肯定线性无关."

> 「易错提醒 · $\Delta < 0$ 复根情形」特征根是**共轭复根** $\alpha \pm \beta i$, **不是**两个实根. 欧拉公式: $\mathrm{e}^{(\alpha+\beta i)x} = \mathrm{e}^{\alpha x}(\cos\beta x + i\sin\beta x)$, 取实部虚部得到 $\cos\beta x$ 和 $\sin\beta x$ 两部分.

### 4. 性质讨论(必考延伸)

教材 full.md:75-83 给出两个**注**, 这是考研常考的延伸:

**注 (1) · $\mathrm{e}^{rx}$ 项的界性**

当解中含有 $\mathrm{e}^{rx}$ 时:
- $r > 0$ 时, $\mathrm{e}^{rx}$ 在 $x \to +\infty$ 时**无界**
- $r < 0$ 时, $\mathrm{e}^{rx}$ 在 $x \to +\infty$ 时**趋于零**(但 $x \to -\infty$ 时**无界**)

老王原话:"它能考它的什么性质? 对了, 我们可以考它的有界还是无界. 如果 $r > 0$, 那么 $\lim\limits_{x \to +\infty} \mathrm{e}^{rx} = +\infty$, 无界. 如果 $r < 0$, 那么 $\lim\limits_{x \to +\infty} \mathrm{e}^{rx} = 0$, 有界."

**注 (2) · $\cos\beta x$, $\sin\beta x$ 项的周期性**

由于 $\cos\beta x$ 与 $\sin\beta x$ 有周期性, 因此:
- 若解具有周期性, 必须 $\mathrm{e}^{\alpha x} = 1$, 即 $\alpha = 0$
- $\cos\beta x$, $\sin\beta x$ 均有界($\le 1$)

老王原话:"如果 $\alpha = 0$ 就是十步是零, 那么这项显然就没有了, 一的零次方是一, 那么这个就会谈到它的周期性的问题了."

「秒杀技巧 · 通解 → 性质」讨论解的性质时, **先**把通解写出来. 老王原话:"当我们见到讨论这个解的性质的时候, 你首先得把这个解写出来."

## 二、例 15.15 · 齐次 + 极值反求 #必考

> 设函数 $y = y(x)$ 是微分方程 $y'' + y' - 2y = 0$ 的解, 且在 $x=0$ 处 $y(x)$ 取得极值 3, 则 $y(x) = $ \_\_\_\_.

**第 1 步:判类型 + 求通解**

教材 full.md:91-95:
- 特征方程: $r^2 + r - 2 = 0$
- 特征根: $r_1 = -2,\ r_2 = 1$ (不相等实根, $\Delta = 1+8 = 9 > 0$)
- 通解: $y(x) = C_1 \mathrm{e}^{-2x} + C_2 \mathrm{e}^{x}$

**第 2 步:翻译条件**

"在 $x = 0$ 处 $y(x)$ 取得极值 3" → 两个等价条件:
- $y(0) = 3$ (函数值)
- $y'(0) = 0$ (费马定理: 极值点处导数为零)

> 「避坑 · 极值条件翻译」老王原话:"极值点处导数为零, 费马定理对吧?"

**第 3 步:代入求常数**

$y(0) = C_1 + C_2 = 3$

$y'(x) = -2C_1 \mathrm{e}^{-2x} + C_2 \mathrm{e}^{x}$, 代入 $x = 0$ 得 $y'(0) = -2C_1 + C_2 = 0$

联立解得: $C_1 = 1,\ C_2 = 2$

**第 4 步:写出特解**

$$\boxed{y(x) = \mathrm{e}^{-2x} + 2\mathrm{e}^{x}}$$

> 「避坑 · 极值 vs 最值」极值是**局部**概念, 用费马定理 (导数 = 0); 最值要算所有临界点 + 边界值后取最大 / 最小.

## 三、例 15.16 · 齐次 + 初值反求

> 设函数 $y = f(x)$ 满足微分方程 $y'' + 2y' + 5y = 0$, 且 $f(0) = 1,\ f'(0) = -1$, 则 $f(x) = $ \_\_\_\_.

**第 1 步:判类型 + 求通解**

教材 full.md:109-118:
- 特征方程: $r^2 + 2r + 5 = 0$
- $\Delta = 4 - 20 = -16 < 0$ → 共轭复根
- 根: $r_{1,2} = \dfrac{-2 \pm \sqrt{4-20}}{2} = \dfrac{-2 \pm 4i}{2} = -1 \pm 2i$
- 所以 $\alpha = -1,\ \beta = 2$
- 通解: $y = C_1 \mathrm{e}^{-x}\cos 2x + C_2 \mathrm{e}^{-x}\sin 2x$

**第 2 步:代入初值**

$f(0) = C_1 = 1$

$f'(0)$: 求导得
$$f'(x) = -C_1 \mathrm{e}^{-x}\cos 2x - 2C_1 \mathrm{e}^{-x}\sin 2x - C_2 \mathrm{e}^{-x}\sin 2x + 2C_2 \mathrm{e}^{-x}\cos 2x$$

代入 $x = 0$: $f'(0) = -C_1 + 2C_2 = -1$, 即 $-1 + 2C_2 = -1$, 所以 $C_2 = 0$

**第 3 步:写出特解**

$$\boxed{f(x) = \mathrm{e}^{-x}\cos 2x}$$

> 「秒杀技巧」看到初值反求, **不要**先背结论, **先**把通解按教材格式写出来(老王强调:"像这些东西, 大家首先先把它给我备注了"), 然后把 $C_1, C_2$ 当未知数联立.

## 四、二阶常系数**非齐次**线性微分方程

### 1. 概念

**概念**(教材 full.md:123-125): 方程
$$y'' + py' + qy = f(x), \quad f(x) \not\equiv 0$$
称为**二阶常系数非齐次线性微分方程**, 其中 $p, q$ 为常数, $f(x)$ 称为**自由项**.

对应地, 把右端 $f(x)$ 写成 $0$ 的方程 $y'' + py' + qy = 0$ 称为该非齐次方程的**导出方程**.

老王原话:"如果恒为零, 你记住那叫齐次方程是吧? 如果不恒为零, 我们称为叫做二阶常系数非齐次的线性微分方程. 我们有时候也称 $y'' + py' + qy = 0$ 是非齐次方程的导出方程."

### 2. 解的结构(三个核心结论)

**结论 1 · 通解 = 齐通解 + 非齐特解**: #重要  #熟记 

$$y(x) = \underbrace{C_1 y_1(x) + C_2 y_2(x)}_{\text{齐通解}} + \underbrace{y^*(x)}_{\text{非齐特解}}$$

其中 $C_1 y_1 + C_2 y_2$ 是导出方程 $y'' + py' + qy = 0$ 的通解, $y^*$ 是非齐方程的一个特解.

**结论 2 · 自由项可加性**:

若 $y_1^*$ 是 $y'' + py' + qy = f_1(x)$ 的解, $y_2^*$ 是 $y'' + py' + qy = f_2(x)$ 的解, 则 $y_1^* + y_2^*$ 是 $y'' + py' + qy = f_1(x) + f_2(x)$ 的解.

> 「秒杀技巧 · 拆分思想」如果 $f(x)$ 太复杂, **拆**成 $f_1 + f_2$ 分别求特解再加起来.

**结论 3 · 特解之差 = 齐次解**:

设 $y_1^*, y_2^*$ 都是 $y'' + py' + qy = f(x)$ 的特解, 则 $y_1^* - y_2^*$ 是对应齐次方程的解.

> 「避坑 · 这条只在客观题里用」老王原话:"如果 $y_1^*$ 和 $y_2^*$ 都是 $f(x)$ 的特解, 那么它们俩做差一定是对应的导出方程的解, 这个道理其实也很简单, 大家知道你把 $y_1$ 代进去, $y_2$ 带进去以后, 这两个方程一解, 实际上自由项 $f(x) - f(x)$ 就是零了."

### 3. 特解的设定 · 待定系数法 #重要 #熟记 

考研大纲只规定**两种**自由项形式需要会求特解.

#### 类型 ① · $f(x) = P_n(x)\mathrm{e}^{\alpha x}$

特解要设为:
$$\boxed{y^* = \mathrm{e}^{\alpha x} Q_n(x) x^k}$$

**"一看二算三比较"口诀**

| 步骤      | 动作                                        | 说明                                    |
| ------- | ----------------------------------------- | ------------------------------------- |
| **一看**  | 看自由项中的 $\alpha$                           | 就是 $\mathrm{e}^{\alpha x}$ 的 $\alpha$ |
| **二算**  | 算特征根 $r_{1,2}$                            | 解特征方程 $r^2 + pr + q = 0$              |
| **三比较** | 比较 $\alpha$ 与 $r_{1,2}$ 的**相等个数**, 确定 $k$ | 见下表                                   |

![[assets/高阶线性微分方程的求解/高阶线性微分方程的求解-1784616870764.webp]]

> 「避坑 · $P_n(x)$ 改写 $Q_n(x)$ 的规则」原 $P_n(x)$ 是**特殊**多项式(可能缺项), $Q_n(x)$ 是**一般**多项式(全部项都写). 例: 原 $f(x) = 1$ (零次多项式), 写成 $Q_0(x) = a$; 原 $f(x) = 2x$ (一次多项式), 写成 $Q_1(x) = ax + b$. #注意 

> 「秒杀技巧 · 待定系数法的步骤总结」三步走: **一看**自由项中的 $\alpha$ → **二算**特征根 $r_{1,2}$ → **三比较**确定 $k$ 写出待定形式 → 代入求系数.

#### 类型 ② · $f(x) = \mathrm{e}^{\alpha x}[P_m(x)\cos\beta x + P_n(x)\sin\beta x]$

特解要设为:
$$\boxed{y^* = \mathrm{e}^{\alpha x}\left[Q_l^{(1)}(x)\cos\beta x + Q_l^{(2)}(x)\sin\beta x\right] x^k}$$

**口诀**(教材 full.md:165): **一看, 二算, 三比较**.

| 步骤 | 动作 | 说明 |
|------|------|------|
| **一看** | 看自由项中的 $\alpha, \beta$ | 把 $\alpha \pm \beta i$ 当成"复特征根"来看 |
| **二算** | 算特征根 $r_{1,2}$ | 解特征方程 |
| **三比较** | 比较 $\alpha \pm \beta i$ 与 $r_{1,2}$, 确定 $k$ | 见下表 |
![[assets/高阶线性微分方程的求解/高阶线性微分方程的求解-1784617501679.webp]]

**$k$ 的取值规则:

$$k = \begin{cases} 0, & \alpha \pm \beta i \text{ 不是特征根} \\ 1, & \alpha \pm \beta i \text{ 是特征根} \end{cases}$$

> 「避坑 · $\Delta < 0$ 时只能 $k = 0$ 或 $k = 1$」当特征方程判别式小于零时, 特征根本身就是共轭复根 $\alpha_0 \pm \beta_0 i$. 自由项里的 $\alpha \pm \beta i$ 要么等于特征根(此时 $k=1$), 要么不等于(此时 $k=0$). **不会出现 $k=2$ 的情形**, 因为特征方程最多两个根, 一旦 $\alpha \pm \beta i$ 是重根, 那只能是 $\Delta = 0$ 实根情形, 不属于复根比较.

**$l$ 的取值**(教材 full.md:157): $l = \max\{m, n\}$, 即 $m$ 和 $n$ 中的较大者. #重要 

**$Q_l^{(1)}(x)$ 和 $Q_l^{(2)}(x)$**: 都是 $x$ 的 $l$ 次一般多项式。

> 「避坑 · 两个 $Q_l$ 必须用不同下标」$Q_l^{(1)}(x)$ 和 $Q_l^{(2)}(x)$ 的系数下标要区分, 即 $A_l x^l + \cdots + A_0$ 与 $B_l x^l + \cdots + B_0$, **不能**共用同一组系数.

## 五、Heaviside 微分算子法

### 1. 基本约定

**约定**:
- $D = \dfrac{\mathrm{d}}{\mathrm{d}x}$, 所以 $Dy = \dfrac{\mathrm{d}y}{\mathrm{d}x}$, $D^2 y = \dfrac{\mathrm{d}^2 y}{\mathrm{d}x^2}$
- 微分方程 $y'' + py' + qy = f(x)$ 写成 $(D^2 + pD + q)y = f(x)$, 记 $D^2 + pD + q = F(D)$, 称为**算子多项式**
- $F(D)$ 满足普通多项式的运算规则(如因式分解)
- $\dfrac{1}{D}$ 表示**积分**, 且积分常数 $C = 0$

特解公式:
$$\boxed{y^* = \frac{1}{F(D)} f(x)}$$

### 2. 类型 ① · $\dfrac{1}{F(D)}\mathrm{e}^{\alpha x}$ 型(指数函数)

**核心规则**(教材 full.md:189-197):

| 情形  | 条件                                                                                                   | 公式                                                                            | 补偿       |
| --- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | -------- |
| (1) | $F(D)\big\vert_{D=\alpha} \neq 0$                                                                    | $y^* = \dfrac{1}{F(D)\big\vert_{D=\alpha}} \mathrm{e}^{\alpha x}$             | 不补偿      |
| (2) | $F(D)\big\vert_{D=\alpha} = 0$, 但 $F'(D)\big\vert_{D=\alpha} \neq 0$                                 | $y^* = x \cdot \dfrac{1}{F'(D)\big\vert_{D=\alpha}} \mathrm{e}^{\alpha x}$    | 补偿 $x$   |
| (3) | $F(D)\big\vert_{D=\alpha} = 0$, $F'(D)\big\vert_{D=\alpha} = 0$, $F''(D)\big\vert_{D=\alpha} \neq 0$ | $y^* = x^2 \cdot \dfrac{1}{F''(D)\big\vert_{D=\alpha}} \mathrm{e}^{\alpha x}$ | 补偿 $x^2$ |


**注例 1**(教材 full.md:199-205): $y'' + y' - 2y = 2$, 求 $y^*$.

- $F(D) = D^2 + D - 2$, $f(x) = 2 = 2 \cdot \mathrm{e}^{0x}$, 所以 $\alpha = 0$
- $F(D)\big|_{D=0} = 0 + 0 - 2 = -2 \neq 0$
- $y^* = \dfrac{1}{-2} \cdot 2\mathrm{e}^{0x} = -1$

**注例 2**(教材 full.md:207-212): $y'' + y' - 2y = \mathrm{e}^x$, 求 $y^*$.

- $F(D) = D^2 + D - 2$, $\alpha = 1$
- $F(D)\big|_{D=1} = 1 + 1 - 2 = 0$, 一阶导 $F'(D) = 2D + 1$
- $F'(D)\big|_{D=1} = 2 + 1 = 3 \neq 0$
- $y^* = x \cdot \dfrac{1}{3} \mathrm{e}^x = \dfrac{1}{3}x\mathrm{e}^x$

**注例 3**(教材 full.md:215-237): $y'' - 2y' + y = \mathrm{e}^x$, 求 $y^*$.

- $F(D) = D^2 - 2D + 1 = (D-1)^2$, $\alpha = 1$
- $F(D)\big|_{D=1} = 0$, $F'(D)\big|_{D=1} = 2D - 2 = 0$, $F''(D)\big|_{D=1} = 2 \neq 0$
- $y^* = x^2 \cdot \dfrac{1}{2} \mathrm{e}^x = \dfrac{1}{2}x^2 \mathrm{e}^x$

### 3. 类型 ② · $\dfrac{1}{F(D)}\cos\beta x$ 或 $\dfrac{1}{F(D)}\sin\beta x$ 型(三角函数)

**a 类**: $F(D) = D^2 + q$ (只含 $D^2$ 和常数, 没有 $D$ 项)(教材 full.md:239-243).

| 情形 | 条件 | 公式 |
|------|------|------|
| (1) | $(D^2+q)\big\vert_{D=\beta i} \neq 0$ | $y^* = \dfrac{1}{(D^2+q)\big\vert_{D=\beta i}}\cos\beta x$ |
| (2) | $(D^2+q)\big\vert_{D=\beta i} = 0$ | $y^* = x \cdot \dfrac{1}{(D^2+q)'}\cos\beta x$ |

> 「避坑 · 求导后不代值」老王特别强调: "**求完导之后不再代值了**." 例: 注例 5 求导 $2D$ 后, **直接**写 $\dfrac{1}{2D}$ 作用在 $\sin 2x$ 上, 不再把 $D = 2i$ 代入.

**注例 4**(教材 full.md:259-264): $y'' - y = \sin x$, 求 $y^*$.

- $F(D) = D^2 - 1$, $\beta = 1$
- $(D^2 - 1)\big|_{D=i} = -1 - 1 = -2 \neq 0$
- $y^* = \dfrac{1}{-2} \sin x = -\dfrac{1}{2}\sin x$

**注例 5**(教材 full.md:267-273): $y'' + 4y = \sin 2x$, 求 $y^*$.

- $F(D) = D^2 + 4$, $\beta = 2$
- $(D^2 + 4)\big|_{D=2i} = -4 + 4 = 0$
- 求导 $(D^2 + 4)' = 2D$, **不代值**
- $y^* = x \cdot \dfrac{1}{2D} \sin 2x = \dfrac{1}{2}x \cdot \dfrac{1}{D}\sin 2x = \dfrac{1}{2}x \cdot (-\cos 2x) = -\dfrac{1}{4}x\cos 2x$
	- $\dfrac{1}{D}\sin 2x$ 相当于对 $\sin 2x$ 积分

**b 类**: $F(D) = D^2 + pD + q$ (含 $D$ 项)(教材 full.md:245-257).

**核心规则**(教材 full.md:250-254): 把 $D^2$ 用 $(\beta i)^2 = -\beta^2$ 代入, 得到 $pD + (q - \beta^2)$, 然后用"上下乘共轭因式"消 $D$:

$$y^* = \frac{pD - (q-\beta^2)}{p^2 D^2 - (q-\beta^2)^2}\cos\beta x \bigg|_{D^2 = -\beta^2} = \frac{pD - (q-\beta^2)}{-p^2\beta^2 - (q-\beta^2)^2}\cos\beta x$$

> 「避坑 · 代入规则」"**只**带 $D^2$, **不带 $D$**". 老王原话:"我们只带 $D^2$, $D$ 是不带进去的."

**注例 6**(教材 full.md:275-281): $y'' - 3y' + 2y = -\dfrac{1}{2}\cos 2x$, 求 $y^*$.

- $F(D) = D^2 - 3D + 2$, $\beta = 2$, $D^2 = -4$ 代入得 $-4 - 3D + 2 = -3D - 2$
- 提负号: $\dfrac{1}{-3D-2} = -\dfrac{1}{3D+2}$
- 上下乘 $3D-2$: $\dfrac{3D-2}{(3D)^2 - 2^2} = \dfrac{3D-2}{9D^2-4}$, 把 $D^2 = -4$ 代入得 $-36-4 = -40$
- $y^* = -\dfrac{1}{2} \cdot \dfrac{3D-2}{-40}\cos 2x = \dfrac{1}{80}(3D\cos 2x - 2\cos 2x)$
- 算 $D\cos 2x = -2\sin 2x$
- $y^* = \dfrac{1}{80}(-6\sin 2x - 2\cos 2x)$

**最终化简**(教材 full.md:281):
$$y^* = \frac{1}{40}(3\sin 2x + \cos 2x)$$

### 4. 类型 ③ · $\dfrac{1}{F(D)}(x^k + a_1 x^{k-1} + \cdots + a_k)$ 型(多项式)

**核心规则**(教材 full.md:283-289): 把 $\dfrac{1}{F(D)}$ 写成 $\dfrac{1}{1 - x}$ 形式的**泰勒展开**, 展开到 $k$ 次多项式为止($k+1$ 次导数归零就停).

老王原话:"你把它除过来, 写成 $\dfrac{1}{F(D)}$ 之后, 你要想办法实际上就是把 $\dfrac{1}{1-x}$ 这样的形式找到, 然后展开到多少, 那就看这个自由项后面的它是多少次方, 它是多少次方, 我就到多少次方就足够了."

**注例 7**(教材 full.md:291-310): $y'' + y' = x^2 + 1$, 求 $y^*$.

- $F(D) = D^2 + D$, 提出 $D$: $\dfrac{1}{D(D+1)} = \dfrac{1}{D} \cdot \dfrac{1}{1+D}$
- 把 $\dfrac{1}{1+D}$ 用泰勒展开到 2 次: $1 - D + D^2 + \cdots$
- $y^* = \dfrac{1}{D} \cdot (1 - D + D^2)(x^2 + 1)$
- 展开: $\dfrac{1}{D}(x^2+1) - (x^2+1) + D(x^2+1)$
- $= \dfrac{1}{3}x^3 + x - x^2 - 1 + 2x = \dfrac{1}{3}x^3 - x^2 + 3x - 1$

> 「避坑 · 展开次数」老王原话:"$x^{k+1}$ 大家知道如果是 $x$ 的 $k$ 次多项式, 你做 $k+1$ 阶导数它就是零了. ... 我这个标准就出来了, 你是二次, 我只要展开多少次就够了."

### 5. 类型 ④ · $\dfrac{1}{F(D)}\mathrm{e}^{\alpha x}v(x)$ 型(指数函数 + 其他函数)

**核心规则**(教材 full.md:319): 把 $\mathrm{e}^{\alpha x}$ 挪到外面, 然后 $D$ 做平移 $D \to D + \alpha$:

$$y^* = \frac{1}{F(D)}\mathrm{e}^{\alpha x}v(x) = \mathrm{e}^{\alpha x} \cdot \frac{1}{F(D+\alpha)}v(x)$$

老王原话:"先把 $\mathrm{e}^{\alpha x}$ 把它挪过来, 挪到 $\dfrac{1}{F(D)}$ 右边去. ... 挪过来之后, 实际上不是对整个层级进行微分子, 而是把它挪回去, 然后再把 $D$ 做一个平移, $F(D)$ 就是 $D$ 做了个平移, 用 $F(D+\alpha)$, 实际上做了个平移."

**注例 8**(教材 full.md:321-326): $y'' + 4y' + 5y = \mathrm{e}^{-2x}\sin x$, 求 $y^*$.

- $F(D) = D^2 + 4D + 5$, $v(x) = \sin x$, $\alpha = -2$
- 挪 $\mathrm{e}^{-2x}$ 到外: $y^* = \mathrm{e}^{-2x} \cdot \dfrac{1}{(D-2)^2 + 4(D-2) + 5}\sin x$
- 展开: $(D-2)^2 + 4(D-2) + 5 = D^2 - 4D + 4 + 4D - 8 + 5 = D^2 + 1$
- 回到类型 ② a: $y^* = \mathrm{e}^{-2x} \cdot \dfrac{1}{D^2+1}\sin x$
- $\beta = 1$, $(D^2+1)\big|_{D=i} = -1 + 1 = 0$, 求导 $2D$ 不代值
- $y^* = \mathrm{e}^{-2x} \cdot x \cdot \dfrac{1}{2D}\sin x = \dfrac{1}{2}\mathrm{e}^{-2x} \cdot x \cdot (-\cos x) = -\dfrac{1}{2}x\mathrm{e}^{-2x}\cos x$

**注例 9**(教材 full.md:329-334): $y'' - 3y' + 2y = 2x\mathrm{e}^x$, 求 $y^*$. 综合以上多种方法.

- $F(D) = D^2 - 3D + 2$, $\alpha = 1$, $v(x) = 2x$
- 平移: $y^* = 2\mathrm{e}^x \cdot \dfrac{1}{(D+1)^2 - 3(D+1) + 2}x$
- 展开: $(D+1)^2 - 3(D+1) + 2 = D^2 + 2D + 1 - 3D - 3 + 2 = D^2 - D$
- $y^* = 2\mathrm{e}^x \cdot \dfrac{1}{D(D-1)}x = 2\mathrm{e}^x \cdot \dfrac{1}{D} \cdot \dfrac{1}{D-1}x$
- 把 $\dfrac{1}{D-1}$ 写成 $\dfrac{-1}{1-D} = -(1 + D + D^2 + \cdots)$, 一次多项式取前两项: $-1 - D$
- $y^* = 2\mathrm{e}^x \cdot \dfrac{1}{D} \cdot (-1 - D)x = 2\mathrm{e}^x \cdot (-\dfrac{1}{D}x - x)$
- $\dfrac{1}{D}x = \dfrac{1}{2}x^2$
- $y^* = 2\mathrm{e}^x \cdot (-\dfrac{1}{2}x^2 - x) = -x(x+2)\mathrm{e}^x$


## 七、易错提醒(踩坑汇总)

> [!warning] **核心坑 1:线性无关判别**
> $\dfrac{y_1}{y_2} = C$(常数) → 线性相关, **不能**做线性组合当通解. 例: $r_1 = r_2$ 时, $\mathrm{e}^{r_1 x}$ 与 $\mathrm{e}^{r_2 x}$ 是**同一个**函数, 必须改用 $(C_1 + C_2 x)\mathrm{e}^{rx}$.

> [!warning] **核心坑 2:特征根判别式的三种情形**
> - $\Delta > 0$: 两个**不等实根**, 直接 $C_1\mathrm{e}^{r_1 x} + C_2\mathrm{e}^{r_2 x}$
> - $\Delta = 0$: **二重根**, 必须凑出 $x\mathrm{e}^{rx}$
> - $\Delta < 0$: **共轭复根** $\alpha \pm \beta i$, 用欧拉公式展开

> [!warning] **核心坑 3:待定系数法 $k$ 的取值**
> - $\alpha$ 不是特征根 → $k = 0$
> - $\alpha$ 是单特征根 → $k = 1$
> - $\alpha$ 是二重特征根 → $k = 2$
>
> 自由项是 $\mathrm{e}^{\alpha x}[P_m \cos\beta x + P_n \sin\beta x]$ 时, 比较的是 $\alpha \pm \beta i$ 与 $r_{1,2}$, 只可能 $k = 0$ 或 $k = 1$.

> [!warning] **核心坑 4:待定系数法 $Q_n(x)$ 必须写全**
> 即使原 $P_n(x)$ 缺某一项, $Q_n(x)$ 必须按 $n$ 次**一般多项式**写全. 例: 原 $f(x) = 1$ 写成 $Q_0(x) = a$, 原 $f(x) = 2x$ 写成 $Q_1(x) = ax + b$.

> [!warning] **核心坑 5:Heaviside 算子法求导后不代值**
> 类型 ② a 类($F(D) = D^2 + q$)求导后, **不**把 $D = \beta i$ 代入, 直接用求导结果(如 $2D$)参与后续计算.

> [!warning] **核心坑 6:Heaviside 类型 ② b 类只带 $D^2$ 不带 $D$**
> 把 $D^2$ 用 $(\beta i)^2 = -\beta^2$ 代入, $D$ 项**不动**, 得到 $pD + (q - \beta^2)$ 这种线性表达式. 然后用"上下乘共轭"消 $D$.

> [!warning] **核心坑 7:Heaviside 类型 ④ $D$ 平移规则**
> 看到 $\mathrm{e}^{\alpha x} v(x)$, 先挪 $\mathrm{e}^{\alpha x}$ 到外面, 再把 $F(D)$ 中的 $D$ 全部替换成 $D + \alpha$. 替换**只**在算子多项式里做, $v(x)$ 不动.

> [!warning] **核心坑 8:微分算子法不是"标准答案"**
> 考研大题标准答案用**待定系数法**. Heaviside 法**只是**客观题加速 / 快速检验, 大题答案不写 Heaviside 过程. 老王原话:"你如果记住这个方法, 你可能做这些题目就是待定系数法, 你不用了, 就是用这个 Heaviside 算子法也能把这个结构做出来. 你要为了确保自己万无一失, 两个方法都用一下, 殊途同归, 你肯定是正确的."
